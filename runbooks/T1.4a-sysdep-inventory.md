# Runbook T1.4a — Inventory of platform-specific code (READ-ONLY)

Goal: list the operating-system specific code, so the supervisor can design a new
"emscripten" platform. You only READ and REPORT. No changes in `upstream/`.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT) — Report: `ROOT/reports/T1.4a.md`

## Step 1 — Platform folders

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source/lib/sysdep
find . -maxdepth 3 -type d | sort
for d in os/unix os/linux os/osx os/bsd os/android os/win arch; do printf '%-12s files=%s lines=%s\n' "$d" "$(find $d -type f 2>/dev/null | wc -l | tr -d ' ')" "$(cat $(find $d -type f -name '*.cpp' -o -type f -name '*.h' 2>/dev/null) 2>/dev/null | wc -l | tr -d ' ')"; done
ls os/unix os/linux os/osx os/android 2>/dev/null
```

## Step 2 — Platform macros

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
grep -n 'define OS_\|define ARCH_' lib/sysdep/os.h lib/sysdep/arch.h
for m in OS_LINUX OS_MACOSX OS_UNIX OS_ANDROID OS_BSD OS_WIN ARCH_X86_X64 ARCH_ARM ARCH_AARCH64 ARCH_IA32; do
  printf '%-14s uses=%-5s files=%s\n' "$m" "$(grep -rwn "$m" --include='*.cpp' --include='*.h' . | wc -l | tr -d ' ')" "$(grep -rlw "$m" --include='*.cpp' --include='*.h' . | wc -l | tr -d ' ')"
done
```

## Step 3 — Files outside lib/sysdep that check OS_ or ARCH_ macros

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
grep -rlE '\b(OS_[A-Z]+|ARCH_[A-Z0-9_]+)\b' --include='*.cpp' --include='*.h' . | grep -v '^./lib/sysdep/' | grep -v '/tests/' | sort
```

## Step 4 — How premake picks platform source folders

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/build/premake
grep -nE 'sysdep|os\.istarget|"unix"|"linux"|"osx"|"android"|"bsd"' premake5.lua | head -60
```

## Step 5 — Threads, timers, filesystem, dynamic libraries

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
for p in 'pthread_' 'std::thread' 'clock_gettime' 'mmap' 'dlopen' 'sysconf' 'sched_' 'fork(' 'execv' 'popen' 'getrlimit' 'cpuid' '__builtin_ia32' 'xmmintrin' 'arm_neon' 'SDL_GL_' 'SDL_Vulkan'; do
  printf '%-18s files=%s\n' "$p" "$(grep -rlF -- "$p" --include='*.cpp' --include='*.h' . | grep -v '/tests/' | wc -l | tr -d ' ')"
done
```
