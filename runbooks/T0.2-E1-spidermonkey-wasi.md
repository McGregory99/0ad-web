# Runbook T0.2-E1 — Experiment: build SpiderMonkey 128 for wasm32-wasi

This is an EXPERIMENT. It may fail, and a failure with a clear error message is a
useful result. Your job is to run the steps and capture exactly what happens.

Goal: compile the same SpiderMonkey 0 A.D. uses (mozjs 128.13.0 + 0 A.D. patches)
into WebAssembly static libraries (`libjs_static.a`, `libjsrust.a`), without JIT,
using the WASI SDK. This is the recipe Mozilla/Bytecode Alliance use for WASI.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT)
- You may create ONLY: `ROOT/wasm/spidermonkey/`, `ROOT/tools/wasi-sdk/`, `ROOT/tools/rustup/`, `ROOT/tools/cargo/`
- Do NOT touch `ROOT/upstream/` (another worker is building there). You only READ the patch files from it.
- Logs: `ROOT/runs/` — Report: `ROOT/reports/T0.2-E1.md`
- Use at most 4 parallel jobs (`-j4`); another build is running on this machine.

## Step 1 — Get the SpiderMonkey source used by 0 A.D.

```bash
mkdir -p ~/DEVELOPMENT/0ad-web/wasm/spidermonkey ~/DEVELOPMENT/0ad-web/tools ~/DEVELOPMENT/0ad-web/runs
cd ~/DEVELOPMENT/0ad-web/wasm/spidermonkey
curl -fLo mozjs-128.13.0.tar.xz https://releases.wildfiregames.com/libs/mozjs-128.13.0.tar.xz; echo "EXIT=$?"
tar xfJ mozjs-128.13.0.tar.xz --exclude=js/src/tests/non262 --exclude=js/src/tests/test262 --exclude=js/src/jit-test --exclude=python/mozperftest --exclude=testing/web-platform --exclude=third_party/rust/mp4parse/link-u-avif-sample-images; echo "EXIT=$?"
ls mozjs-128.13.0 | head -30
```

Expected: both `EXIT=0`; the listing contains `mach` and `js`.

## Step 2 — Apply the 0 A.D. patches

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/spidermonkey/mozjs-128.13.0
P=../../../upstream/libraries/source/spidermonkey/patches
for f in FixRustLinkage.diff FixLibNames.diff FixPkgConfigDebug.diff FixExtraGCTracing.diff SuppressDanglingPointerWarning.patch FixPython3_14.diff; do
  echo "== $f"; patch -p1 < "$P/$f" || echo "PATCH FAILED: $f"
done
```

Expected: no `PATCH FAILED` line. (We skip `FixMacOSBuild.diff` on purpose: the target is wasm, not macOS.)

## Step 3 — Download the WASI SDK (version 24)

```bash
cd ~/DEVELOPMENT/0ad-web/tools
curl -s https://api.github.com/repos/WebAssembly/wasi-sdk/releases/tags/wasi-sdk-24 | grep browser_download_url
```

From that list, pick the URL that contains `arm64-macos.tar.gz`. Then (replace URL):

```bash
cd ~/DEVELOPMENT/0ad-web/tools
curl -fLo wasi-sdk.tar.gz "URL"; echo "EXIT=$?"
mkdir -p wasi-sdk && tar xzf wasi-sdk.tar.gz -C wasi-sdk --strip-components=1; echo "EXIT=$?"
xattr -dr com.apple.quarantine wasi-sdk 2>/dev/null
./wasi-sdk/bin/clang --version | head -1
ls wasi-sdk/share/wasi-sysroot
```

Expected: a clang version line, and the sysroot folder lists `include` and `lib`.
If there is no `arm64-macos` file, STOP and paste the full URL list in the report.

## Step 4 — Install a private Rust 1.79 toolchain with the wasm32-wasi target

This installs Rust ONLY inside `ROOT/tools/` (it does not change the user's Rust).

```bash
export RUSTUP_HOME=~/DEVELOPMENT/0ad-web/tools/rustup CARGO_HOME=~/DEVELOPMENT/0ad-web/tools/cargo
~/.cargo/bin/rustup toolchain install 1.79.0-aarch64-apple-darwin --profile minimal --no-self-update > ~/DEVELOPMENT/0ad-web/runs/T0.2-E1-rust.log 2>&1; echo "EXIT=$?"
~/.cargo/bin/rustup target add wasm32-wasi --toolchain 1.79.0-aarch64-apple-darwin >> ~/DEVELOPMENT/0ad-web/runs/T0.2-E1-rust.log 2>&1; echo "EXIT=$?"
ls ~/DEVELOPMENT/0ad-web/tools/rustup/toolchains/1.79.0-aarch64-apple-darwin/bin/
~/DEVELOPMENT/0ad-web/tools/rustup/toolchains/1.79.0-aarch64-apple-darwin/bin/rustc --print target-list | grep wasm32-wasi
```

Expected: both `EXIT=0`, `rustc` and `cargo` listed, and `wasm32-wasi` printed.

## Step 5 — Write the build configuration

Create `~/DEVELOPMENT/0ad-web/wasm/spidermonkey/mozconfig-wasi` with EXACTLY:

```
ac_add_options --enable-project=js
ac_add_options --target=wasm32-unknown-wasi
ac_add_options --host=aarch64-apple-darwin
ac_add_options --disable-jit
ac_add_options --disable-shared-js
ac_add_options --disable-shared-memory
ac_add_options --disable-tests
ac_add_options --disable-js-shell
ac_add_options --disable-jemalloc
ac_add_options --without-intl-api
ac_add_options --disable-clang-plugin
ac_add_options --disable-debug
ac_add_options --enable-optimize=-O2
ac_add_options --enable-portable-baseline-interp
mk_add_options MOZ_OBJDIR=@TOPSRCDIR@/obj-wasi
mk_add_options AUTOCLOBBER=1
```

## Step 6 — Build

Create `~/DEVELOPMENT/0ad-web/wasm/spidermonkey/build-wasi.sh` with EXACTLY:

```bash
#!/bin/sh
set -e
ROOT="$HOME/DEVELOPMENT/0ad-web"
WASI="$ROOT/tools/wasi-sdk"
TC="$ROOT/tools/rustup/toolchains/1.79.0-aarch64-apple-darwin/bin"
export RUSTUP_HOME="$ROOT/tools/rustup" CARGO_HOME="$ROOT/tools/cargo"
export RUSTC="$TC/rustc" CARGO="$TC/cargo" PATH="$TC:$PATH"
export CC="$WASI/bin/clang --sysroot=$WASI/share/wasi-sysroot"
export CXX="$WASI/bin/clang++ --sysroot=$WASI/share/wasi-sysroot"
export AR="$WASI/bin/llvm-ar"
export HOST_CC=/usr/bin/clang HOST_CXX=/usr/bin/clang++
export MOZCONFIG="$ROOT/wasm/spidermonkey/mozconfig-wasi"
export MOZ_NOSPAM=1 MACH_BUILD_PYTHON_NATIVE_PACKAGE_SOURCE=none
export MOZBUILD_STATE_PATH="$ROOT/wasm/spidermonkey/mozbuild-state"
export CFLAGS="-w" CXXFLAGS="-w"
cd "$ROOT/wasm/spidermonkey/mozjs-128.13.0"
/opt/homebrew/bin/python3.12 ./mach build -j4
```

Then run it:

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/spidermonkey && chmod +x build-wasi.sh
./build-wasi.sh > ~/DEVELOPMENT/0ad-web/runs/T0.2-E1-build.log 2>&1; echo "EXIT=$?"
tail -n 60 ~/DEVELOPMENT/0ad-web/runs/T0.2-E1-build.log
```

This can take 20–60 minutes.

If `EXIT` is not 0: do NOT change anything. Run these and put the output in the report:

```bash
grep -nE "error|Error|ERROR" ~/DEVELOPMENT/0ad-web/runs/T0.2-E1-build.log | head -40
```

and STOP.
