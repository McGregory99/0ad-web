# Runbook T0.2-E1e — Build zlib for wasi, then retry SpiderMonkey

Supervisor diagnosis of attempt 4: configure passed and compiling started, then
`obj-wasi/dist/system_wrappers/zlib.h: fatal error: 'zlib.h' file not found`.
Standalone SpiderMonkey always uses a "system" zlib; the wasi sysroot has none.
Fix: build zlib 1.3.2 with wasi-sdk into `ROOT/wasm/deps/wasi-prefix`. The supervisor
already updated `build-wasi.sh` (CFLAGS/LDFLAGS/PKG_CONFIG point there) and touched
`mozconfig-wasi` so configure runs again.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT)
- You may create ONLY: `ROOT/wasm/deps/wasi-src/`, `ROOT/wasm/deps/wasi-prefix/`
- Report: append `## Attempt 5 (wasi zlib)` to `ROOT/reports/T0.2-E1.md`

## Step 1 — Build zlib for wasi (source is already on disk, no download)

```bash
W=~/DEVELOPMENT/0ad-web/tools/wasi-sdk
P=~/DEVELOPMENT/0ad-web/wasm/deps/wasi-prefix
mkdir -p ~/DEVELOPMENT/0ad-web/wasm/deps/wasi-src "$P"
cp -R ~/DEVELOPMENT/0ad-web/tools/emsdk/upstream/emscripten/cache/ports/zlib/zlib-1.3.2 ~/DEVELOPMENT/0ad-web/wasm/deps/wasi-src/
cd ~/DEVELOPMENT/0ad-web/wasm/deps/wasi-src/zlib-1.3.2
CC="$W/bin/clang --sysroot=$W/share/wasi-sysroot" AR="$W/bin/llvm-ar" RANLIB="$W/bin/llvm-ranlib" CFLAGS="-O2" \
  ./configure --static --prefix="$P" > ~/DEVELOPMENT/0ad-web/runs/T0.2-E1e-zlib.log 2>&1; echo "CONFIGURE EXIT=$?"
make libz.a >> ~/DEVELOPMENT/0ad-web/runs/T0.2-E1e-zlib.log 2>&1; echo "MAKE EXIT=$?"
make install >> ~/DEVELOPMENT/0ad-web/runs/T0.2-E1e-zlib.log 2>&1; echo "INSTALL EXIT=$?"
ls "$P/include" "$P/lib" "$P/lib/pkgconfig"
"$W/bin/llvm-nm" "$P/lib/libz.a" | grep -c ' T '
```

Expected: three `EXIT=0`, `zlib.h` + `zconf.h`, `libz.a`, `zlib.pc`, and a count above 50.
If `make install` fails but `libz.a` exists, run instead:
`mkdir -p "$P/include" "$P/lib/pkgconfig" && cp zlib.h zconf.h "$P/include/" && cp libz.a "$P/lib/" && cp zlib.pc "$P/lib/pkgconfig/"`
Any other failure: paste the last 40 lines of the log and STOP.
