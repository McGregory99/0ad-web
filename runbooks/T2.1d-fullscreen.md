# Runbook T2.1d — Fullscreen toggle (worker t13, port 8105)

Read `runbooks/_wave5-common.md` first. Report: `reports/T2.1d.md`. No code edits.

Background (supervisor): the game toggles fullscreen with Alt+Enter (`togglefullscreen` hotkey).
Browsers allow fullscreen only inside a user gesture. The probe `runs/T2.1d/fs.js` (already written)
returns whether the page is fullscreen and the window, screen and canvas sizes.

## Step 1 — Own copy (no build)
No-build copy command from `_wave5-common.md` (worker t13).

## Step 2 — Run A: toggle in the main menu (windowed start)
```bash
F=runs/T2.1d/fs.js
CHROME_GPU=1 perl -e 'alarm shift; exec @ARGV' 180 node tools/web/chrome-shot.mjs runs/web-t13 runs/T2.1d/toggle \
  "wait:25,click:491:553,wait:2,evalfile:$F,shot:before,keydown:Alt,key:Enter,keyup:Alt,wait:3,evalfile:$F,shot:full,keydown:Alt,key:Enter,keyup:Alt,wait:3,evalfile:$F,shot:back,key:Escape,wait:2,evalfile:$F" \
  '?arg=-mod=public&arg=-conf=windowed:true' 8105
grep -E 'evalfile|ERROR|fullscreen|Fullscreen|exception' runs/T2.1d/toggle/console.log
```

## Step 3 — Run B: start without `windowed:true` (the game's default is fullscreen)
```bash
CHROME_GPU=1 perl -e 'alarm shift; exec @ARGV' 120 node tools/web/chrome-shot.mjs runs/web-t13 runs/T2.1d/default \
  "wait:25,evalfile:$F,shot:start,click:491:553,wait:3,evalfile:$F,shot:afterclick" \
  '?arg=-mod=public' 8105
grep -E 'evalfile|ERROR|fullscreen|Fullscreen|exception' runs/T2.1d/default/console.log
```
