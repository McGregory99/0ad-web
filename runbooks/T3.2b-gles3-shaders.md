## Step 2 — The change
In `upstream/source/renderer/backend/gl/ShaderProgram.cpp` find this block (around line 720):
```cpp
#if CONFIG2_GLES
			// Ugly hack to replace desktop GLSL 1.10/1.20 with GLSL ES 1.00,
```
Change only the line `#if CONFIG2_GLES` of THAT block into the following (the original block then
becomes the `#elif` branch; keep its lines and its closing `#endif` unchanged):
```cpp
#if CONFIG2_GLES && defined(__EMSCRIPTEN__)
			// WebGL2: compile the GLSL 1.10/1.20 sources as GLSL ES 3.00, which has real shadow
			// samplers (GLSL ES 1.00 on WebGL has none, so shadows were blocky). The prelude maps the
			// removed built-ins; gl_FragColor/gl_FragData are renamed in the text because gl_-prefixed
			// names are reserved for macros.
			{
				const bool fragment = type == GL_FRAGMENT_SHADER;
				CStr prelude = "#version 300 es\nprecision highp float;\nprecision highp sampler2DShadow;\n"
					"#define texture2D texture\n#define textureCube texture\n#define shadow2D(s, c) vec4(texture(s, c))\n";
				prelude += fragment
					? "#define varying in\nlayout(location = 0) out vec4 zeroad_FragData[4];\n"
					: "#define attribute in\n#define varying out\n";
				for (const char* version : {"#version 110\n", "#version 110\r\n", "#version 120\n", "#version 120\r\n"})
					source.Replace(version, prelude);
				if (fragment)
				{
					source.Replace("gl_FragColor", "zeroad_FragData[0]");
					source.Replace("gl_FragData", "zeroad_FragData");
				}
			}
#elif CONFIG2_GLES
```
Check: `sed -n 715,750p upstream/source/renderer/backend/gl/ShaderProgram.cpp` shows the new branch, then
`#elif CONFIG2_GLES`, the old comment + 4 `source.Replace` lines, then `#endif`.
