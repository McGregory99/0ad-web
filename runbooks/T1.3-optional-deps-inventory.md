## Steps

For EACH row of the table, run these three commands (replace PATTERN with the row's pattern, keep the quotes):

```bash
cd ~/DEVELOPMENT/0ad-web/upstream
grep -rIlE "PATTERN" source --include='*.cpp' --include='*.h' | grep -v '/tests/' | sort | wc -l
grep -rIlE "PATTERN" source --include='*.cpp' --include='*.h' | grep -v '/tests/' | sort | head -40
grep -rIcE "PATTERN" source --include='*.cpp' --include='*.h' | grep -v ':0$' | grep -v '/tests/' | sort -t: -k2 -nr | head -10
```

Then, for the macro rows (3, 4, 5), also run:

```bash
grep -rIn "MACRO" source --include='*.cpp' --include='*.h' | wc -l
```

Then run once:

```bash
cd ~/DEVELOPMENT/0ad-web/upstream
grep -nE 'without-|_OPTIONS|newoption' build/premake/premake5.lua | head -40
grep -nE '"libcurl"|"enet"|"gloox"|"miniupnpc"|"nvtt"|"fcollada"|"sdl"|"openal"|"spidermonkey"|"icu"|"sodium"|"freetype"|"libxml2"|"libpng"|"zlib"|"vorbis"|"fmt"|"boost"' build/premake/premake5.lua | head -60
```
