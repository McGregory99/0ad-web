# Runbook T0.5b — Fix the PBL crash with upstream bug 1909656 (worker t05)

Read `runbooks/_wave7-common.md` first. Report: `reports/T0.5b.md`. Logs: `runs/T0.5b/`.

## Background (supervisor)

SpiderMonkey's portable baseline interpreter (PBL) is ~3x faster than the C++ interpreter on our
workload, but with PBL on, the wasm replay crashed at turns ~4812/4924/5004 (`reports/T0.5a.md`),
so PBL is off (`JIT_OPTION_portableBaselineInterpreter=false`). Research found the likely cause:
upstream **bug 1909656** ("Don't push callee token for native calls in PBL", Firefox 130, never
in ESR 128). PBL pushes the callee token in the wrong place for native calls, so GC traces the
native exit frame one word off: on wasm32 that reads garbage Values (crash mode a) and misses the
last argument, e.g. a sort comparator moved by a minor GC (crash mode b). A second small upstream
hardening fix, **bug 2061321** (stack check ignores formal-argument padding), goes with it.
Both patches are in `runs/T0.5b/fix1909656.patch` and `runs/T0.5b/fix2061321.patch`
(from github.com/mozilla-firefox/firefox commits b2d86ba15366 and e83443ea1399).
2061321 needs hand-applying near `js/src/vm/PortableBaselineInterpret.cpp:6325-6333`; on wasm32
`std::max(size_t, ssize_t)` does not compile, so use a `size_t` for the formal count.

Our SpiderMonkey: `wasm/spidermonkey/mozjs-128.13.0` (build dir `obj-wasi`), built by
`wasm/spidermonkey/build-wasi.sh`; the engine links the installed copy (find how
`wasm/spidermonkey/dist-wasm` is filled: read `reports/T0.2-E1*.md` and the end of
`build-wasi.sh`). `wasm/` is git-ignored, so the tracked copies of our SpiderMonkey patches go in
`patches/spidermonkey/`.

## Step 1 — Apply the patches
```bash
cd wasm/spidermonkey/mozjs-128.13.0
cp js/src/vm/PortableBaselineInterpret.cpp ../../../runs/T0.5b/PortableBaselineInterpret.cpp.orig
patch -p1 --dry-run < ../../../runs/T0.5b/fix1909656.patch && patch -p1 < ../../../runs/T0.5b/fix1909656.patch
patch -p1 --dry-run < ../../../runs/T0.5b/fix2061321.patch; echo EXIT=$?
cd ../../..
```
If the 2061321 dry run fails, apply its change by hand (read the .patch). Then write both tracked
patch files with
`diff -u runs/T0.5b/PortableBaselineInterpret.cpp.orig wasm/spidermonkey/mozjs-128.13.0/js/src/vm/PortableBaselineInterpret.cpp`
split by hunk (one file per fix, paths `a/js/src/vm/...` / `b/js/src/vm/...`, a 3-line header
comment naming the bug and the upstream commit URL). Show the final diff in the report.

variables. Copy it to `runs/T0.5b/ai-replay-pbl.sh`, change only that word to `true`, and fix
`ROOT` in the copy so it still points at the repository root (it is computed from the script's
location). Then:

Expected: all three finish 12,419 turns with hash `6908836f…`, no `RuntimeError`.
