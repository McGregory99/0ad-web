# Runbook T4.3d — ICU usage and a smaller ICU data file (worker t13, READ-ONLY)

Read `runbooks/_wave5-common.md` first. Report: `reports/T4.3d.md`. No edits except files under
`runs/T4.3d/`.

Context: the web build preloads `/icu/icudt68l.dat` (28.6 MB) before the menu. Goal: find what
the engine actually uses from ICU, and how a filtered data file could be built.

## Step 1 — ICU APIs used by the engine
```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
grep -rnE 'unicode/[a-z0-9_]+\.h' --include='*.cpp' --include='*.h' . | grep -v /tests/ | sed -E 's/.*(unicode\/[a-z0-9_]+\.h).*/\1/' | sort | uniq -c | sort -rn
grep -rnE '\bicu::[A-Za-z]+|\bu(col|brk|cal|num|dat|loc|trans|norm)_[a-zA-Z]+' --include='*.cpp' --include='*.h' . | grep -v /tests/ | head -60
grep -rnE 'tinygettext|L10n::' ps/l10n* i18n 2>/dev/null | head -20
ls ps | grep -i l10n
```
List which ICU services are used: collation, break iteration, date/number formatting, calendars,
transliteration, normalization, converters, locale display names.

## Step 2 — Which locales the game ships
```bash
cd ~/DEVELOPMENT/0ad-web
unzip -l upstream/binaries/data/mods/public/public.zip 'l10n/*.po' 2>/dev/null | awk '{print $4}' | sed -E 's#.*/([a-zA-Z_@]+)\.[^/]*\.po#\1#' | sort -u | tr '\n' ' '
ls upstream/binaries/data/mods/mod/l10n 2>/dev/null | head
```
(If public.zip is not at that path, find it: `find upstream/binaries -name public.zip -maxdepth 6`.)

## Step 3 — How the data file is built today
```bash
grep -rnE 'icudt|icu' tools/wasm/*.sh tools/wasm/*.md 2>/dev/null | head -20
find ~/DEVELOPMENT/0ad-web/wasm -maxdepth 3 -iname '*icu*' | head
find ~/DEVELOPMENT/0ad-web -maxdepth 5 -name 'icudt68l.dat' -exec ls -l {} \; 2>/dev/null
```
Find the ICU 68 source used for the wasm build (`find ~/DEVELOPMENT/0ad-web -maxdepth 5 -type d -name 'icu*'`).
Check whether it has `source/data/` and `source/python/icutools/databuilder` (needed for
`ICU_DATA_FILTER_FILE`). Report the paths.

## Step 4 — Proposed filter (write, do not run a build)
Write `runs/T4.3d/icu-filter.json` (ICU data filter format, docs: `docs/userguide/icu_data/buildtool.md`
inside the ICU source if present) keeping only: the categories from Step 1, the locales from
Step 2 (plus `root` and `en`). Explain each kept category in one line.
