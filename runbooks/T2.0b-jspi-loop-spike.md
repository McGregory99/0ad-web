# Runbook T2.0b — Browser spike 2: blocking game loop + JSPI on the main thread

Context: T2.0 showed the main-thread variant runs at 60 FPS; the worker-thread variant fails
(SDL2 + OffscreenCanvas). 0 A.D. has a blocking `while` loop. This spike keeps such a loop and
yields to the browser every frame with JSPI (a Chrome feature that lets wasm wait for JS promises).
It also checks C++ exceptions (`-fwasm-exceptions`) and an HTTP Range read. The supervisor wrote
`tools/spikes/jspi-loop/main.cpp`. Do NOT edit it.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT). Write only in `ROOT/tools/spikes/jspi-loop/out-*`, `ROOT/runs/`,
  `mktemp -d` dirs. Report: `ROOT/reports/T2.0b.md`. If a step fails: paste output, STOP.

Every shell starts with:

```bash
source ~/DEVELOPMENT/0ad-web/tools/emsdk/emsdk_env.sh > /dev/null 2>&1; emcc --version | head -1
```

## Step 1 — Build two variants (yield with setTimeout, yield with requestAnimationFrame)

```bash
cd ~/DEVELOPMENT/0ad-web/tools/spikes/jspi-loop && mkdir -p out-sleep out-raf
COMMON="-O2 -pthread -fwasm-exceptions -sJSPI=1 -sUSE_SDL=2 -sMAX_WEBGL_VERSION=2 -sMIN_WEBGL_VERSION=2 -sFULL_ES3=1"
em++ main.cpp $COMMON -o out-sleep/index.html; echo "SLEEP EXIT=$?"
em++ main.cpp $COMMON -DYIELD_RAF -o out-raf/index.html; echo "RAF EXIT=$?"
cp main.cpp out-sleep/; cp main.cpp out-raf/
ls -la out-sleep out-raf
```

## Step 2 — Run each in headless Chrome for 30 seconds

```bash
cd ~/DEVELOPMENT/0ad-web/tools/spikes
C="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
for v in sleep raf; do
  node serve.mjs jspi-loop/out-$v 8092 > ~/DEVELOPMENT/0ad-web/runs/T2.0b-$v-server.log 2>&1 &
  S=$!
  P=$(mktemp -d); echo "CHROME PROFILE DIR ($v)=$P"
  perl -e 'alarm shift; exec @ARGV' 30 "$C" --headless=new --user-data-dir=$P --no-first-run \
    --enable-logging=stderr --v=0 --use-angle=swiftshader --enable-unsafe-swiftshader \
    http://127.0.0.1:8092/ > ~/DEVELOPMENT/0ad-web/runs/T2.0b-$v-chrome.log 2>&1
  kill $S
  echo "=== $v"
  grep -E 'CONSOLE' ~/DEVELOPMENT/0ad-web/runs/T2.0b-$v-chrome.log | grep -vE 'GPU stall' | head -20
  grep -cE 'FPS' ~/DEVELOPMENT/0ad-web/runs/T2.0b-$v-chrome.log
done
```

Expected for both: `EXCEPTION_CAUGHT 1`, `FETCH status=206 bytes=8 text=...`, `GL_VERSION ...`,
several `FPS` lines, and `LOOP DONE` (1200 frames: ~20 s at 60 FPS).
