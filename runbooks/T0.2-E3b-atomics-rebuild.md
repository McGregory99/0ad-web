# Runbook T0.2-E3b — Rebuild SpiderMonkey and zlib with atomics, then relink the engine

The engine links with shared memory (threads). wasm-ld refuses objects built without the
`atomics`/`bulk-memory` features (`--shared-memory is disallowed by jsmath.o ...`). The supervisor
added `-matomics -mbulk-memory` (and Rust `+atomics,+bulk-memory`) to `build-wasi.sh` and touched
`mozconfig-wasi` so configure runs again.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT). You may write only under `ROOT/wasm/` and `ROOT/runs/`.
- Report: `ROOT/reports/T0.2-E3b.md`

## Step 1 — Rebuild zlib for wasi with atomics

```bash
W=~/DEVELOPMENT/0ad-web/tools/wasi-sdk; P=~/DEVELOPMENT/0ad-web/wasm/deps/wasi-prefix
cd ~/DEVELOPMENT/0ad-web/wasm/deps/wasi-src/zlib-1.3.2
make clean > /dev/null 2>&1
CC="$W/bin/clang --sysroot=$W/share/wasi-sysroot" CFLAGS="-O2 -matomics -mbulk-memory" \
  ./configure --static --prefix="$P" > ~/DEVELOPMENT/0ad-web/runs/T0.2-E3b-zlib.log 2>&1; echo "CONFIGURE EXIT=$?"
make libz.a AR="$W/bin/llvm-ar" ARFLAGS=rc RANLIB="$W/bin/llvm-ranlib" >> ~/DEVELOPMENT/0ad-web/runs/T0.2-E3b-zlib.log 2>&1; echo "MAKE EXIT=$?"
cp libz.a "$P/lib/libz.a"; "$W/bin/llvm-nm" "$P/lib/libz.a" | grep -c ' T '
```

Expected: two `EXIT=0` and a count above 50.

## Step 2 — Rebuild SpiderMonkey (several minutes)

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/spidermonkey
./build-wasi.sh > ~/DEVELOPMENT/0ad-web/runs/T0.2-E3b-build.log 2>&1; echo "BUILD EXIT=$?"
tail -n 5 ~/DEVELOPMENT/0ad-web/runs/T0.2-E3b-build.log
```

If BUILD EXIT is not 0: `grep -nE "ERROR|error:" ~/DEVELOPMENT/0ad-web/runs/T0.2-E3b-build.log | head -40`, paste, STOP.

## Step 3 — Package and relink the engine (the supervisor's scripts)

```bash
cd ~/DEVELOPMENT/0ad-web
./tools/wasm/package-mozjs.sh > runs/T0.2-E3b-package.log 2>&1; echo "PACKAGE EXIT=$?"
./tools/wasm/build-engine.sh; echo "ENGINE EXIT=$?"
grep -E 'disallowed by' runs/engine-make.log | sed -E 's/.*disallowed by ([^ ]+).*/\1/' | sort | uniq -c | sort -rn | head -30
grep -oE 'undefined symbol: [^(]*' runs/engine-make.log | sort | uniq -c | sort -rn | head -40
```

A non-zero ENGINE EXIT is expected (the supervisor is still writing the platform layer).
The question is ONLY whether the `disallowed by` lines are gone.
