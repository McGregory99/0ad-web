# Runbook T0.2-E2 — Link the wasm SpiderMonkey into an Emscripten program and run it in Node

Experiment. Question: can Emscripten link the libraries built with wasi-sdk (E1), and does
JavaScript run? The supervisor wrote the test program `ROOT/tools/smoke/js_hello.cpp`.
Expected risks: undefined symbols (wasi vs Emscripten libc), and `-pthread` refusing objects
built without atomics. We WANT to see those errors if they happen: capture them, do not fix.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT)
- You may create ONLY files under `ROOT/wasm/e2/`
- Report: `ROOT/reports/T0.2-E2.md` — logs in `ROOT/runs/`

Every shell you open must start with:

```bash
source ~/DEVELOPMENT/0ad-web/tools/emsdk/emsdk_env.sh > /dev/null 2>&1
R=~/DEVELOPMENT/0ad-web
O=$R/wasm/spidermonkey/mozjs-128.13.0/obj-wasi
mkdir -p $R/wasm/e2 && cd $R/wasm/e2
emcc --version | head -1
```

## Step 1 — Link WITHOUT threads

```bash
em++ -std=c++20 -O2 -I$O/dist/include $R/tools/smoke/js_hello.cpp \
  $O/js/src/build/libjs_static.a $O/wasm32-wasi/release/libjsrust.a $R/wasm/deps/wasi-prefix/lib/libz.a \
  -sSTACK_SIZE=8MB -sINITIAL_MEMORY=256MB -sALLOW_MEMORY_GROWTH=1 \
  -o js_hello.js > $R/runs/T0.2-E2-link1.log 2>&1; echo "EXIT=$?"
grep -c 'undefined symbol' $R/runs/T0.2-E2-link1.log
grep -oE 'undefined symbol: [^ ]+' $R/runs/T0.2-E2-link1.log | sort | uniq -c | sort -rn | head -60
tail -n 15 $R/runs/T0.2-E2-link1.log
```

If `EXIT=0`, go to Step 3. Otherwise do Step 2.

## Step 2 — Only if Step 1 failed: list ALL missing symbols

```bash
em++ -std=c++20 -O2 -I$O/dist/include $R/tools/smoke/js_hello.cpp \
  $O/js/src/build/libjs_static.a $O/wasm32-wasi/release/libjsrust.a $R/wasm/deps/wasi-prefix/lib/libz.a \
  -sSTACK_SIZE=8MB -sINITIAL_MEMORY=256MB -sALLOW_MEMORY_GROWTH=1 -sERROR_ON_UNDEFINED_SYMBOLS=0 \
  -o js_hello.js > $R/runs/T0.2-E2-link2.log 2>&1; echo "EXIT=$?"
grep -oE 'undefined symbol: [^ ]+' $R/runs/T0.2-E2-link2.log | sort -u > missing-symbols.txt; wc -l missing-symbols.txt
cat missing-symbols.txt | head -100
```

## Step 3 — Run it in Node (only if a `js_hello.js` was produced)

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/e2
ls -la js_hello.js js_hello.wasm
( time node js_hello.js ) > $R/runs/T0.2-E2-run.log 2>&1; echo "EXIT=$?"
tail -n 30 $R/runs/T0.2-E2-run.log
```

Expected success line: `JS OK 7,<number>`.

## Step 4 — Try WITH threads (always do this step)

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/e2
em++ -std=c++20 -O2 -pthread -I$O/dist/include $R/tools/smoke/js_hello.cpp \
  $O/js/src/build/libjs_static.a $O/wasm32-wasi/release/libjsrust.a $R/wasm/deps/wasi-prefix/lib/libz.a \
  -sSTACK_SIZE=8MB -sINITIAL_MEMORY=256MB -sALLOW_MEMORY_GROWTH=1 -sERROR_ON_UNDEFINED_SYMBOLS=0 \
  -o js_hello_mt.js > $R/runs/T0.2-E2-link-mt.log 2>&1; echo "EXIT=$?"
grep -iE 'error|atomics|bulk-memory|shared-memory' $R/runs/T0.2-E2-link-mt.log | head -20
```
