1. GPL-2.0-or-later for engine + data: full license text available/linked, and a written offer or
   link to the complete corresponding source of the exact shipped wasm build (from
   `upstream/LICENSE.md`: `source/` and `binaries/data/` are GPL-2.0+).

   `gui/page_credits.xml` are inside `public.zip` (observed in `unzip -l`).

   LinBiolinum (GPLv3+ with exception), Source Han Sans (OFL 1.1 with Reserved Font Name
   'Source') — each license file is inside `mod.zip` under `fonts/`.

   tinygettext, fmt, enet, libsodium, libxml2, zlib, libpng, SDL2, Boost, Emscripten, and the
   libcurl headers shipped in the stub (all observed in the license files listed in the table).

   `ports/freetype/freetype-VER-2-14-3/LICENSE.TXT`).

9. SpiderMonkey/MPL 2.0: make MPL-covered source available and do not use Mozilla/Firefox names or
   logos (observed in `wasm/spidermonkey/mozjs-128.13.0/LICENSE`).

**Inferred**:

10. A "no network" statement is safe for the web build because libcurl is a stub
    (`wasm/pkgconfig/libcurl.pc` says "all network calls fail") — the shipped `libcurl.a` contains
    stub code, not curl code.
11. Microsoft dbghelp terms (`license_dbghelp.txt`) do not apply to the web build.
12. The Emscripten MIT/NCSA notice covers the built-in OpenAL implementation, since no separate
    OpenAL license file exists in our tree.
13. Boost headers shipped through the emscripten `boost_headers` port are under BSL-1.0 even though
    the port directory has no license file (the license was read from the bundled macOS copy).
