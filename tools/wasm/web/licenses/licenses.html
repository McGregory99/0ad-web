0 A.D. in the browser — licenses and source

This is an unofficial browser port of 0 A.D., the free, open-source real-time strategy game by Wildfire Games (http://www.wildfiregames.com/). It is not made or endorsed by Wildfire Games. All game code and content belong to Wildfire Games and its contributors and are used here under the licenses below.
