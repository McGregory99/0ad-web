# Runbook T2.3a — Audio starts after the first click (worker t01, port 8101)

Read `runbooks/_wave4-common.md` first. Report: `reports/T2.3a.md`. Logs: `runs/T2.3a-*`.

Goal: browsers create an AudioContext "suspended" until the user clicks or presses a key. The game
uses Emscripten's OpenAL, which keeps its contexts in the global `AL.contexts`. We resume them on input.

## Step 4 — The change
Append this block to the END of `tools/wasm/web-env.pre.js` (keep the tabs):
```js
// Browsers start an AudioContext suspended until a user gesture. OpenAL (library_openal.js) keeps its
// contexts in AL.contexts; resume any suspended one on input. Contexts can appear later, so keep listening.
{
	const resumeAudio = () => {
		if (typeof AL === 'undefined' || !AL.contexts) return;
		for (const context of Object.values(AL.contexts)) {
			if (context && context.audioCtx && context.audioCtx.state === 'suspended') context.audioCtx.resume();
		}
	};
	for (const type of ['pointerdown', 'keydown', 'touchend']) addEventListener(type, resumeAudio, { capture: true });
}
```
