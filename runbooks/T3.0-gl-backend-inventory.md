# Runbook T3.0 — Inventory of the OpenGL backend and shaders (READ-ONLY on source)

Goal: list exactly which OpenGL functions, constants and shader features the engine
uses, so the supervisor can compare them with what WebGL2 supports. You only READ
and REPORT. You do not change anything in `upstream/`.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT)
- You may create ONLY: `ROOT/wasm/inventory/` (extracted shaders and lists)
- Report: `ROOT/reports/T3.0.md`

## Step 1 — Size of the GL backend

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
ls renderer/backend/gl/
wc -l renderer/backend/gl/*.cpp renderer/backend/gl/*.h | tail -1
grep -rn 'CONFIG2_GLES' --include='*.cpp' --include='*.h' . | wc -l
grep -rln 'CONFIG2_GLES' --include='*.cpp' --include='*.h' . | sort
```

## Step 2 — OpenGL functions and constants used anywhere in `source/` (tests excluded)

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
mkdir -p ~/DEVELOPMENT/0ad-web/wasm/inventory
grep -rhoE '\bgl[A-Z][A-Za-z0-9]+\b' --include='*.cpp' --include='*.h' . | grep -v '/tests/' | sort | uniq -c | sort -rn > ~/DEVELOPMENT/0ad-web/wasm/inventory/gl-functions.txt
grep -rhoE '\bGL_[A-Z0-9_]+\b' --include='*.cpp' --include='*.h' . | sort | uniq -c | sort -rn > ~/DEVELOPMENT/0ad-web/wasm/inventory/gl-constants.txt
wc -l ~/DEVELOPMENT/0ad-web/wasm/inventory/gl-functions.txt ~/DEVELOPMENT/0ad-web/wasm/inventory/gl-constants.txt
```

## Step 3 — Constants that WebGL2 does NOT have (quick filter)

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/inventory
grep -E 'GL_(QUADS|POLYGON|CLAMP\b|ALPHA_TEST|TEXTURE_1D|POLYGON_MODE|LINE\b|FILL\b|POINT\b|LIGHTING|FOG|CLIP_PLANE|ARB|EXT|NV|ATI|APPLE|S3TC|COMPRESSED|DEPTH_COMPONENT32|TEXTURE_BORDER|GENERATE_MIPMAP|MULTISAMPLE|ANISOTROPY|DEBUG|TIMESTAMP|QUERY|BGRA|LUMINANCE|INTENSITY)' gl-constants.txt > gl-constants-suspect.txt
wc -l gl-constants-suspect.txt
```

## Step 4 — Extract the shaders from the game data

```bash
cd ~/DEVELOPMENT/0ad-web
mkdir -p wasm/inventory/shaders
unzip -o -q data/mods/mod/mod.zip 'shaders/*' -d wasm/inventory/shaders/mod
unzip -o -q data/mods/public/public.zip 'shaders/*' -d wasm/inventory/shaders/public
find wasm/inventory/shaders -type f | sed 's/.*\.//' | sort | uniq -c
find wasm/inventory/shaders -path '*glsl*' -type f | wc -l
```

## Step 5 — Shader features that need changes for WebGL2 (GLSL ES 3.00)

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/inventory/shaders
for p in '#version' '#extension' 'texture2D' 'textureCube' 'shadow2D' 'gl_FragColor' 'gl_FragData' 'attribute ' 'varying ' 'precision ' 'texture2DLod' 'gl_ModelViewProjectionMatrix' 'gl_TexCoord' 'gl_Color' 'GL_ARB' 'GL_EXT'; do
  printf '%-30s %s\n' "$p" "$(grep -rl -- "$p" . | wc -l | tr -d ' ')"
done
grep -rhoE '#version [0-9]+( [a-z]+)?' . | sort | uniq -c
grep -rhoE '#extension [A-Za-z0-9_]+' . | sort | uniq -c
```
