## Verdict on "can `?ai=remote` become the default?"

**Not yet (observed).** With a fresh build the worker does start and the remote path looks healthy for ~22 minutes — 60 fps, p99 16.7 ms, a worst single AI call of 478 ms that did not stall the frame loop — and it is clearly smoother than the in-process run (worst frame 33.3 ms vs 83.3 ms). But at 1338.1 s the module traps with `RuntimeError: null function`, every AI and bridge counter freezes, and the picture stops updating for the remaining ~8 minutes while the page still reports 60 fps. A default that silently ends the match after 22 minutes, with a healthy-looking fps meter, is worse than the current in-process default; the null-function trap must be fixed and this run repeated first.
