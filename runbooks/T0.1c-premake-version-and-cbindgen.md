# Runbook T0.1c — Rebuild premake with its own version, then resume the native build

Supervisor diagnosis:
1. `premake5 --version` prints `0.28.0`. When premake is built, it runs `git describe`,
   and git finds the 0 A.D. repository around it (tag `v0.28.0`). The game then refuses it:
   "Requires Premake 5.0.0-beta5 or later". Fix: build premake with git disabled
   (`GIT_DIR=/nonexistent`), so it reads its own `git-tags.txt` (5.0.0-beta7).
2. SpiderMonkey needs `cbindgen`. It is already installed at `ROOT/tools/cargo/bin/cbindgen`.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT)
- Report: append `## Attempt T0.1c` to `ROOT/reports/T0.1.md`

Every shell you open for this runbook must start with:

```bash
export TC=~/DEVELOPMENT/0ad-web/tools/rustup/toolchains/1.79.0-aarch64-apple-darwin/bin
export RUSTC="$TC/rustc" CARGO="$TC/cargo" PATH="$TC:$PATH"
export CBINDGEN=~/DEVELOPMENT/0ad-web/tools/cargo/bin/cbindgen
export MAKE=make JOBS=-j6
"$CBINDGEN" --version
```

Expected: `cbindgen 0.26.0`.

## Step 1 — Rebuild premake without git

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/libraries/source/premake-core
GIT_DIR=/nonexistent ./build.sh --force-rebuild > ~/DEVELOPMENT/0ad-web/runs/T0.1c-premake.log 2>&1; echo "EXIT=$?"
tail -n 5 ~/DEVELOPMENT/0ad-web/runs/T0.1c-premake.log
./bin/premake5 --version
```

Expected: `EXIT=0` and `premake5 (Premake Build Script Generator) 5.0.0-beta7`.
If the version still says `0.28.0`, STOP and report.
