# Runbook T0.3a — Early gate estimate: native replay with the JIT switched off

The browser build has no JIT (SpiderMonkey runs as an interpreter). Before the wasm engine
exists, we measure how much slower the native replay gets without JIT. SpiderMonkey reads
`JIT_OPTION_*` environment variables.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT) — Report: `ROOT/reports/T0.3a.md`
- Reference: native replay with JIT = about 35–38 s, final state `6908836f8d8ca50562faab971ad0c4ca`.

## Step 1 — Three runs (each can take several minutes; run them one after the other)

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/binaries/system
REPLAY="$HOME/DEVELOPMENT/0ad-web/fixtures/reference-replay/commands.txt"
L=~/DEVELOPMENT/0ad-web/runs

# A: default (JIT on)
/usr/bin/time -p ./pyrogenesis -replay="$REPLAY" > $L/T0.3a-A-jit.log 2>&1; echo "A EXIT=$?"

# B: only the baseline interpreter (no compiled JIT code)
JIT_OPTION_ion=false JIT_OPTION_baselineJit=false \
/usr/bin/time -p ./pyrogenesis -replay="$REPLAY" > $L/T0.3a-B-blinterp.log 2>&1; echo "B EXIT=$?"

# C: plain C++ interpreter (closest to the browser build)
JIT_OPTION_ion=false JIT_OPTION_baselineJit=false JIT_OPTION_baselineInterpreter=false JIT_OPTION_nativeRegExp=false \
/usr/bin/time -p ./pyrogenesis -replay="$REPLAY" > $L/T0.3a-C-interp.log 2>&1; echo "C EXIT=$?"
```

## Step 2 — Collect results

```bash
cd ~/DEVELOPMENT/0ad-web/runs
for f in T0.3a-A-jit.log T0.3a-B-blinterp.log T0.3a-C-interp.log; do
  echo "== $f"; grep 'Final state' $f; grep -E '^(real|user|sys) ' $f; grep -ciE 'mismatch|error' $f
done
```
