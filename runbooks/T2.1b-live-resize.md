# Runbook T2.1b — Window resize while the game runs (worker t01, port 8103)

Read `runbooks/_wave5-common.md` first. Report: `reports/T2.1b.md`.

Context: T2.1a showed the game starts correctly at 1920x1080, 1024x768 and 800x600. Players also
resize the browser window while playing. Goal: check that the canvas, the GUI layout and mouse
clicks follow a live resize.

Allowed edits: `tools/web/chrome-shot.mjs` only — add a step `resize:<w>:<h>` that calls
`Emulation.setDeviceMetricsOverride` with the new size and `Browser.setWindowBounds` is NOT needed.
Update the usage comment at the top of the file for the new step.

## Step 1 — Add the step, check syntax
`node --check tools/web/chrome-shot.mjs; echo "EXIT=$?"`

## Step 2 — Menu resize
`runs/T2.1b/canvas.js`:
```js
(() => { const c = document.querySelector('canvas'); return JSON.stringify({ win: [innerWidth, innerHeight], css: [c.clientWidth, c.clientHeight], buf: [c.width, c.height] }); })()
```
Use the no-build copy command (your copy `runs/web-t01`).
```bash
perl -e 'alarm shift; exec @ARGV' 200 node tools/web/chrome-shot.mjs runs/web-t01 runs/T2.1b/menu \
  "wait:25,evalfile:runs/T2.1b/canvas.js,shot:a1280,resize:1600:900,wait:3,evalfile:runs/T2.1b/canvas.js,shot:b1600,resize:900:700,wait:3,evalfile:runs/T2.1b/canvas.js,shot:c900" \
  "?arg=-mod=public&arg=-conf=windowed:true" 8103
grep -E 'evalfile|error|Error' runs/T2.1b/menu/console.log; sips -g pixelWidth -g pixelHeight runs/T2.1b/menu/*.png
```
Expected: `css` and `buf` follow `win` after each resize.

## Step 3 — Clicks after a resize
The main-menu "Single player" button is at (491, 553) at 1280x720. After `resize:1600:900` the
menu re-lays out; find the new position by scaling (x*1600/1280, y*900/720 → 614, 691) and also try the
unscaled point. Run: `wait:25,resize:1600:900,wait:3,click:614:691,wait:2,shot:sp_scaled` and a second run
with `click:491:553`. Report which one opened the single-player submenu (compare md5 with a shot
taken without any click: `wait:25,resize:1600:900,wait:5,shot:noclick`).

## Step 4 — Resize during a match
```bash
CHROME_GPU=1 perl -e 'alarm shift; exec @ARGV' 260 node tools/web/chrome-shot.mjs runs/web-t01 runs/T2.1b/game \
  "wait:25,$START,wait:40,shot:g1280,fps:5,resize:1600:900,wait:4,evalfile:runs/T2.1b/canvas.js,shot:g1600,fps:5,resize:1024:640,wait:4,evalfile:runs/T2.1b/canvas.js,shot:g1024,fps:5" \
  "?arg=-mod=public&arg=-conf=windowed:true" 8103
grep -E 'evalfile|fps|error|Error' runs/T2.1b/game/console.log
```
