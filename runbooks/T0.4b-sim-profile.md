# Runbook T0.4b — Which part of the simulation makes the slow turns slow? (profile native vs wasm)

Context: T0.4a showed the slow wasm turns are NOT garbage collection: they are turns where the
JavaScript work is 10–15x slower than native. The replay mode already writes a profiler table every
20 turns (`profile.txt` in the user log folder). We collect it for native and wasm. IMPORTANT: the
wasm run MUST set `JIT_OPTION_portableBaselineInterpreter=false` (without it, it crashes ~turn 4900;
that was the supervisor's mistake in T0.4a). You COLLECT logs only; no code changes, no debugging.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT). Write only in `ROOT/runs/` and `mktemp -d` dirs.
  Do NOT rebuild anything. Report: `ROOT/reports/T0.4b.md`. If a step fails: paste output, STOP.

## Step 1 — Native replay (about 1 minute)

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/binaries/system
R=~/DEVELOPMENT/0ad-web; H=$(mktemp -d); echo "TEMP HOME=$H"
HOME=$H perl -e 'alarm shift; exec @ARGV' 900 ./pyrogenesis -replay="$R/fixtures/reference-replay/commands.txt" 2>&1 \
  | node $R/tools/bench/turnstats.mjs $R/runs/T0.4b-native.tsv > $R/runs/T0.4b-native.stats
cat $R/runs/T0.4b-native.stats
find $H -name 'profile*' -exec ls -la {} \;
cp "$(find $H -name profile.txt | head -1)" $R/runs/T0.4b-native-profile.txt; echo "COPY EXIT=$?"
```

## Step 2 — Wasm replay with PBL OFF (several minutes, limit 30)

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/binaries/system-wasm
R=~/DEVELOPMENT/0ad-web; H2=$(mktemp -d); echo "TEMP HOME=$H2"
HOME=$H2 ZEROAD_EXECUTABLE=$PWD/pyrogenesis JIT_OPTION_portableBaselineInterpreter=false perl -e 'alarm shift; exec @ARGV' 1800 \
  node pyrogenesis -replay="$R/fixtures/reference-replay/commands.txt" 2>&1 \
  | node $R/tools/bench/turnstats.mjs $R/runs/T0.4b-wasm.tsv > $R/runs/T0.4b-wasm.stats
cat $R/runs/T0.4b-wasm.stats
find $H2 -name 'profile*' -exec ls -la {} \;
cp "$(find $H2 -name profile.txt | head -1)" $R/runs/T0.4b-wasm-profile.txt; echo "COPY EXIT=$?"
ls -la $R/runs/T0.4b-*
```

Expected: both `.stats` files start with `# Final state: 6908836f8d8ca50562faab971ad0c4ca`.
