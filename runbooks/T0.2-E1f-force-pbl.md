# Runbook T0.2-E1f — Turn on the portable baseline interpreter and measure the speed-up

Supervisor finding: our wasm SpiderMonkey contains the "portable baseline interpreter" (PBL),
but it is OFF by default, so it runs the slow C++ interpreter. The supervisor added
`--enable-portable-baseline-interp-force` to `wasm/spidermonkey/mozconfig-wasi`.
We measure a benchmark BEFORE and AFTER the rebuild. Benchmark source: `ROOT/tools/smoke/js_bench.cpp`.
Expected result text (both runs): `JS OK 7,540434,-125005,100 eval_ms=<number>`.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT). You may create files under `ROOT/wasm/e2/` only.
- Report: `ROOT/reports/T0.2-E1f.md`

Every shell you open must start with:

```bash
source ~/DEVELOPMENT/0ad-web/tools/emsdk/emsdk_env.sh > /dev/null 2>&1
R=~/DEVELOPMENT/0ad-web
O=$R/wasm/spidermonkey/mozjs-128.13.0/obj-wasi
cd $R/wasm/e2
```

The link command used below (call it LINK) is:

```bash
link_bench() {
  em++ -std=c++20 -O2 -I$O/dist/include $R/tools/smoke/js_bench.cpp wasi_compat.o \
    $O/js/src/build/libjs_static.a libmozglue_extra.a $O/wasm32-wasi/release/libjsrust.a $R/wasm/deps/wasi-prefix/lib/libz.a \
    -Wl,--wrap=clock_gettime -sSTACK_SIZE=8MB -sINITIAL_MEMORY=256MB -sALLOW_MEMORY_GROWTH=1 -o "$1"
}
```

Define it in your shell before using it.

## Step 1 — BEFORE: link and run 3 times with the current libraries

```bash
link_bench js_bench_before.js > $R/runs/T0.2-E1f-link-before.log 2>&1; echo "LINK EXIT=$?"
for i in 1 2 3; do node js_bench_before.js; done
```

## Step 2 — Rebuild SpiderMonkey with the new option (several minutes)

```bash
cd $R/wasm/spidermonkey
./build-wasi.sh > $R/runs/T0.2-E1f-build.log 2>&1; echo "BUILD EXIT=$?"
tail -n 5 $R/runs/T0.2-E1f-build.log
grep -n 'PORTABLE_BASELINE' $O/js/src/js-confdefs.h
```

Expected: `BUILD EXIT=0` and a line with `ENABLE_PORTABLE_BASELINE_INTERP_FORCE`.
If BUILD EXIT is not 0: `grep -nE "ERROR|error:" $R/runs/T0.2-E1f-build.log | head -40`, paste, STOP.

## Step 3 — Rebuild the mozglue archive (objects were recompiled)

```bash
cd $O && find mfbt mozglue memory -name '*.o' | sort > $R/wasm/e2/mozglue-objects.txt && wc -l $R/wasm/e2/mozglue-objects.txt
rm -f $R/wasm/e2/libmozglue_extra.a
$R/tools/wasi-sdk/bin/llvm-ar rcs $R/wasm/e2/libmozglue_extra.a $(cat $R/wasm/e2/mozglue-objects.txt); echo "AR EXIT=$?"
cd $R/wasm/e2
```

## Step 4 — AFTER: link and run 3 times

```bash
link_bench js_bench_after.js > $R/runs/T0.2-E1f-link-after.log 2>&1; echo "LINK EXIT=$?"
for i in 1 2 3; do node js_bench_after.js; done
node js_hello.js
```
