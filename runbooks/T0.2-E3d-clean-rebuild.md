- Root: `~/DEVELOPMENT/0ad-web` (ROOT). You may write/delete only under `ROOT/wasm/spidermonkey/mozjs-128.13.0/obj-wasi`, `ROOT/wasm/spidermonkey/dist-wasm`, `ROOT/upstream/build/workspaces/emscripten`, `ROOT/upstream/binaries/system-wasm` and `ROOT/runs/`.

## Step 1 — Delete the old build directory

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/spidermonkey/mozjs-128.13.0
grep -c 'wasm32-wasip1-threads' build/moz.configure/rust.configure
rm -rf obj-wasi; ls -d obj-wasi 2>/dev/null || echo "obj-wasi removed"
```

Expected: `3` and `obj-wasi removed`.

## Step 2 — Full build (can take 10–30 minutes)

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/spidermonkey
/usr/bin/time -p ./build-wasi.sh > ~/DEVELOPMENT/0ad-web/runs/T0.2-E3d-build.log 2>&1; echo "BUILD EXIT=$?"
grep -n 'rust target triplet' ~/DEVELOPMENT/0ad-web/runs/T0.2-E3d-build.log
grep -E '^(real|user) ' ~/DEVELOPMENT/0ad-web/runs/T0.2-E3d-build.log
ls -la mozjs-128.13.0/obj-wasi/wasm32-wasip1-threads/release/libjsrust.a mozjs-128.13.0/obj-wasi/js/src/build/libjs_static.a
```

Expected: `BUILD EXIT=0`, the triplet line says `wasm32-wasip1-threads`, both files exist.
If BUILD EXIT is not 0: `grep -nE "ERROR|error:" ~/DEVELOPMENT/0ad-web/runs/T0.2-E3d-build.log | head -40`, paste, STOP.

## Step 3 — Package and relink the engine

```bash
cd ~/DEVELOPMENT/0ad-web
./tools/wasm/package-mozjs.sh > runs/T0.2-E3d-package.log 2>&1; echo "PACKAGE EXIT=$?"
./tools/wasm/build-engine.sh; echo "ENGINE EXIT=$?"
ls -la runs/engine-make.log
grep -E 'disallowed by' runs/engine-make.log | head -10
grep -oE 'undefined symbol: [^(]*' runs/engine-make.log | sort | uniq -c | sort -rn | head -40
grep -nE 'error' runs/engine-make.log | grep -v 'undefined symbol' | tail -20 | cut -c1-300
ls -la upstream/binaries/system-wasm/ | grep -i pyrogenesis
```

A non-zero ENGINE EXIT is possible. Paste every output.
