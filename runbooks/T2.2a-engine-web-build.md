## Step 2 — Node smoke test and the reference replay (PBL off; several minutes, limit 30)

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/binaries/system-wasm
R=~/DEVELOPMENT/0ad-web; H=$(mktemp -d); echo "TEMP HOME=$H"
HOME=$H ZEROAD_EXECUTABLE=$PWD/pyrogenesis perl -e 'alarm shift; exec @ARGV' 120 node pyrogenesis -version; echo "VERSION EXIT=$?"
HOME=$H ZEROAD_EXECUTABLE=$PWD/pyrogenesis JIT_OPTION_portableBaselineInterpreter=false perl -e 'alarm shift; exec @ARGV' 1800 \
  node pyrogenesis -replay="$R/fixtures/reference-replay/commands.txt" 2>&1 \
  | node $R/tools/bench/turnstats.mjs $R/runs/T2.2a-node-replay.tsv > $R/runs/T2.2a-node-replay.stats
cat $R/runs/T2.2a-node-replay.stats
```

Expected: `Pyrogenesis ...` and a stats file starting with `# Final state: 6908836f8d8ca50562faab971ad0c4ca`.
