# Runbook T2.0 — Browser spike: SDL2 + WebGL2 with a frame callback, on a worker thread vs the main thread

Context: 0 A.D. will run in Chrome. The supervisor wrote a tiny test program
(`tools/spikes/webgl-loop/main.c`: SDL2 window, OpenGL ES 3 = WebGL2, a color that changes every
frame, prints `FPS ...` once per second) and a small web server (`tools/spikes/serve.mjs`, adds the
COOP/COEP headers that threads need). You build it twice and check both in headless Chrome.
Do NOT edit `main.c` or `serve.mjs`.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT). Write only in `ROOT/tools/spikes/webgl-loop/out-*`,
  `ROOT/runs/` and `mktemp -d` dirs. Report: `ROOT/reports/T2.0.md`
- If a step fails: paste the output in the report and STOP.

Every shell starts with:

```bash
source ~/DEVELOPMENT/0ad-web/tools/emsdk/emsdk_env.sh > /dev/null 2>&1; emcc --version | head -1
```

## Step 1 — Build both variants

```bash
cd ~/DEVELOPMENT/0ad-web/tools/spikes/webgl-loop && mkdir -p out-pthread out-main
COMMON="-O2 -pthread -sUSE_SDL=2 -sMAX_WEBGL_VERSION=2 -sMIN_WEBGL_VERSION=2 -sFULL_ES3=1"
emcc main.c $COMMON -sPROXY_TO_PTHREAD=1 -sOFFSCREENCANVAS_SUPPORT=1 -o out-pthread/index.html; echo "PTHREAD EXIT=$?"
emcc main.c $COMMON -o out-main/index.html; echo "MAIN EXIT=$?"
ls -la out-pthread out-main
```

## Step 2 — Run each variant in headless Chrome for 20 seconds

```bash
cd ~/DEVELOPMENT/0ad-web/tools/spikes
C="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
for v in pthread main; do
  node serve.mjs webgl-loop/out-$v 8091 > ~/DEVELOPMENT/0ad-web/runs/T2.0-$v-server.log 2>&1 &
  S=$!
  P=$(mktemp -d); echo "CHROME PROFILE DIR ($v)=$P"
  perl -e 'alarm shift; exec @ARGV' 20 "$C" --headless=new --user-data-dir=$P --no-first-run \
    --enable-logging=stderr --v=0 --use-angle=swiftshader --enable-unsafe-swiftshader \
    http://127.0.0.1:8091/ > ~/DEVELOPMENT/0ad-web/runs/T2.0-$v-chrome.log 2>&1
  kill $S
  echo "=== $v"
  grep -E 'CONSOLE' ~/DEVELOPMENT/0ad-web/runs/T2.0-$v-chrome.log | grep -E 'FPS|GL_|failed|rror|SharedArrayBuffer' | head -15
  grep -cE 'FPS' ~/DEVELOPMENT/0ad-web/runs/T2.0-$v-chrome.log
done
```

Expected: `GL_VERSION OpenGL ES 3.0 (WebGL 2.0 ...)` and many `FPS` lines for each variant.
The `pthread` variant should print `main_browser_thread=0`, the `main` variant `main_browser_thread=1`.
