# Runbook T1.2 — Third-party libraries for WebAssembly

Goal: make every third-party C/C++ library the engine needs available as
WebAssembly, compiled WITH thread support (`-pthread`). Part A uses libraries
that Emscripten already ships ("ports"). Part B compiles four libraries ourselves.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT)
- You may create ONLY: `ROOT/tools/smoke/ports_check.cpp`, `ROOT/wasm/deps/` (sources, builds, prefix)
- Install prefix for Part B: `ROOT/wasm/deps/prefix`
- Logs: `ROOT/runs/` — Report: `ROOT/reports/T1.2.md`
- Use `-j4` at most (other builds run on this machine).

Every shell you open for this runbook must start with:

```bash
source ~/DEVELOPMENT/0ad-web/tools/emsdk/emsdk_env.sh > /dev/null 2>&1
export PREFIX=~/DEVELOPMENT/0ad-web/wasm/deps/prefix
mkdir -p ~/DEVELOPMENT/0ad-web/wasm/deps/src $PREFIX ~/DEVELOPMENT/0ad-web/runs
```

## Part A — Emscripten ports (zlib, libpng, freetype, ogg, vorbis, SDL2, ICU, boost headers, OpenAL)

Create `ROOT/tools/smoke/ports_check.cpp` with EXACTLY:

```cpp
#include <cstdio>
#include <zlib.h>
#include <png.h>
#include <ft2build.h>
#include FT_FREETYPE_H
#include <ogg/ogg.h>
#include <vorbis/codec.h>
#include <SDL2/SDL.h>
#include <unicode/uversion.h>
#include <boost/version.hpp>
#include <AL/al.h>
#include <AL/alc.h>

int main() {
    std::printf("zlib %s\n", zlibVersion());
    std::printf("libpng %u\n", (unsigned)png_access_version_number());
    FT_Library ft;
    std::printf("freetype init %d\n", (int)FT_Init_FreeType(&ft));
    ogg_sync_state oy; ogg_sync_init(&oy);
    vorbis_info vi; vorbis_info_init(&vi);
    std::printf("ogg+vorbis ok\n");
    SDL_version v; SDL_GetVersion(&v);
    std::printf("SDL %d.%d.%d\n", v.major, v.minor, v.patch);
    UVersionInfo uv; u_getVersion(uv);
    std::printf("ICU %d.%d\n", uv[0], uv[1]);
    std::printf("boost %d\n", BOOST_VERSION);
    std::printf("openal symbol %p\n", (void*)&alcOpenDevice);
    std::printf("PORTS OK\n");
    return 0;
}
```

Build and run (the first build downloads and compiles the ports; it can take 10–20 minutes):

```bash
cd ~/DEVELOPMENT/0ad-web/tools/smoke
em++ -O2 -pthread -sPTHREAD_POOL_SIZE=2 -sEXIT_RUNTIME=1 \
  -sUSE_ZLIB=1 -sUSE_LIBPNG=1 -sUSE_FREETYPE=1 -sUSE_OGG=1 -sUSE_VORBIS=1 \
  -sUSE_SDL=2 -sUSE_ICU=1 -sUSE_BOOST_HEADERS=1 -lopenal \
  ports_check.cpp -o ports_check.js > ~/DEVELOPMENT/0ad-web/runs/T1.2-A-build.log 2>&1; echo "BUILD_EXIT=$?"
tail -n 20 ~/DEVELOPMENT/0ad-web/runs/T1.2-A-build.log
node ports_check.js; echo "RUN_EXIT=$?"
```

Expected: `BUILD_EXIT=0`, the program prints a line per library and ends with `PORTS OK`, `RUN_EXIT=0`.
If the build fails, paste the first 30 lines containing `error` from the log and continue with Part B anyway.

## Part B — Libraries we build ourselves

Do B1–B4 in order. If one fails, record it and continue with the next one.
For each failed one, paste `grep -n -i error <its log> | head -30` in the report.

### B1 — libxml2 2.13.5

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/deps/src
curl -fLO https://download.gnome.org/sources/libxml2/2.13/libxml2-2.13.5.tar.xz && tar xf libxml2-2.13.5.tar.xz
cd libxml2-2.13.5
emcmake cmake -S . -B build-wasm -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=OFF \
  -DLIBXML2_WITH_PYTHON=OFF -DLIBXML2_WITH_ICONV=OFF -DLIBXML2_WITH_LZMA=OFF -DLIBXML2_WITH_ZLIB=OFF \
  -DLIBXML2_WITH_TESTS=OFF -DLIBXML2_WITH_PROGRAMS=OFF -DLIBXML2_WITH_HTTP=OFF -DLIBXML2_WITH_FTP=OFF \
  -DCMAKE_C_FLAGS="-pthread" -DCMAKE_INSTALL_PREFIX=$PREFIX > ~/DEVELOPMENT/0ad-web/runs/T1.2-B1.log 2>&1 \
  && cmake --build build-wasm -j4 >> ~/DEVELOPMENT/0ad-web/runs/T1.2-B1.log 2>&1 \
  && cmake --install build-wasm >> ~/DEVELOPMENT/0ad-web/runs/T1.2-B1.log 2>&1; echo "B1_EXIT=$?"
```
