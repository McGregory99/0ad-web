## Step 1 — Generate makefiles for Emscripten

Supervisor note (retry 2): premake's `--os=emscripten` breaks the 0 A.D. scripts (they only know
linux/windows/macosx/bsd). We generate as `linux` (Unix + pkg-config) with `CC=emcc` so premake
detects the `wasm32` architecture (patch 0003, already applied), and compile with `emmake make`,
which replaces gcc with emcc.

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/build/premake
CC=emcc CXX=em++ ../../libraries/source/premake-core/bin/premake5 --file=premake5.lua --outpath=../workspaces/emscripten \
  --os=linux --gles --with-system-mozjs --without-atlas --without-nvtt --without-collada --without-lobby \
  --without-miniupnpc --without-tests --without-pch gmake > ~/DEVELOPMENT/0ad-web/runs/T1.1-E1-premake.log 2>&1; echo "EXIT=$?"
tail -n 30 ~/DEVELOPMENT/0ad-web/runs/T1.1-E1-premake.log
ls ../workspaces/emscripten
grep -rl 'sysdep/arch/' ../workspaces/emscripten/*.make | head
```

Expected: `EXIT=0`, a `Makefile` plus several `*.make` files, and NO file listed by the last grep.
If `EXIT` is not 0: put the whole log in the report and STOP.

## Step 2 — List the projects

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/build/workspaces/emscripten
grep -E '^PROJECTS|^[a-zA-Z_0-9]+:' Makefile | head -40
grep -h 'CC = \|CXX = \|AR = ' *.make | sort | uniq -c
```

The makefiles may say `gcc`/`g++`: that is fine, because `emmake` overrides `CC`, `CXX` and `AR` in Step 3.

## Step 3 — Compile everything, keep going after errors (can take 30–60 minutes)

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/build/workspaces/emscripten
emmake make config=release -k -j6 > ~/DEVELOPMENT/0ad-web/runs/T1.1-E1-make.log 2>&1; echo "EXIT=$?"
tail -n 20 ~/DEVELOPMENT/0ad-web/runs/T1.1-E1-make.log
```

A non-zero EXIT is expected. Continue.

## Step 4 — Build the error map

```bash
mkdir -p ~/DEVELOPMENT/0ad-web/wasm/errors && cd ~/DEVELOPMENT/0ad-web/wasm/errors
L=~/DEVELOPMENT/0ad-web/runs/T1.1-E1-make.log
grep -E 'error:' $L > all-errors.txt; wc -l all-errors.txt
grep -E 'fatal error: .* file not found' $L | sed -E "s/.*fatal error: '([^']+)'.*/\1/" | sort | uniq -c | sort -rn > missing-headers.txt
sed -E 's/^[^:]*:[0-9]+:[0-9]+: //' all-errors.txt | sed -E "s/'[^']*'/'X'/g" | sort | uniq -c | sort -rn > error-kinds.txt
sed -E 's/:[0-9]+:[0-9]+:.*//' all-errors.txt | sed -E 's#.*/source/##' | sort | uniq -c | sort -rn > files-with-errors.txt
sed -E 's#^([^/]*/[^/]*)/.*#\1#' files-with-errors.txt | awk '{print $2}' | sed -E 's#/[^/]*$##' | sort | uniq -c | sort -rn > dirs-with-errors.txt
grep -E '^==== Building|^Linking|^ar: ' $L | sort | uniq -c | head -40 > projects.txt
grep -cE '\.o$|Compiling|^[A-Za-z_]+\.cpp$' $L
wc -l missing-headers.txt error-kinds.txt files-with-errors.txt
```
