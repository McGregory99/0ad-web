## Step 1 — Build the archive

```bash
cd $O && find mfbt mozglue memory -name '*.o' | sort > $R/wasm/e2/mozglue-objects.txt
wc -l $R/wasm/e2/mozglue-objects.txt
rm -f $R/wasm/e2/libmozglue_extra.a
$W/llvm-ar rcs $R/wasm/e2/libmozglue_extra.a $(cat $R/wasm/e2/mozglue-objects.txt); echo "AR EXIT=$?"
cd $R/wasm/e2 && ls -la libmozglue_extra.a
```

## Step 2 — Link again, show ALL errors

```bash
cd $R/wasm/e2
em++ -std=c++20 -O2 -I$O/dist/include $R/tools/smoke/js_hello.cpp \
  $O/js/src/build/libjs_static.a libmozglue_extra.a $O/wasm32-wasi/release/libjsrust.a $R/wasm/deps/wasi-prefix/lib/libz.a \
  -sSTACK_SIZE=8MB -sINITIAL_MEMORY=256MB -sALLOW_MEMORY_GROWTH=1 -Wl,--error-limit=0 \
  -o js_hello.js > $R/runs/T0.2-E2b-link.log 2>&1; echo "EXIT=$?"
grep -c 'error' $R/runs/T0.2-E2b-link.log
grep -oE '(undefined symbol|duplicate symbol): .*' $R/runs/T0.2-E2b-link.log | sort | uniq -c | sort -rn | head -80
grep -E 'error' $R/runs/T0.2-E2b-link.log | grep -vE 'undefined symbol|duplicate symbol' | head -20
```

## Step 3 — Run in Node (only if `EXIT=0`)
