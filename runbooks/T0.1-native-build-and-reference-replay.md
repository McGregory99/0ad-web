# Runbook T0.1 — Native build + reference replay

Goal: build 0 A.D. 0.28.0 natively on this Mac and record one reference replay
whose simulation hashes we will later compare against the WebAssembly build.

- Root: `~/DEVELOPMENT/0ad-web` (call it ROOT)
- Logs go to: `ROOT/runs/`
- Report goes to: `ROOT/reports/T0.1.md`
- Expected total time: 1–3 hours (most of it is compiling). This is normal.

Before starting, run:

```bash
cd ~/DEVELOPMENT/0ad-web && mkdir -p runs reports fixtures/reference-replay && date
```

Record the start time in the report.

---

## Step 1 — Use the real game data instead of the placeholder files

The source checkout contains Git LFS placeholder files instead of real data.
Replace the two data folders with links to the real data in `ROOT/data/mods/`.

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/binaries/data/mods
mv public public.lfs-pointers
mv mod mod.lfs-pointers
ln -s ../../../../data/mods/public public
ln -s ../../../../data/mods/mod mod
ls -la public/ mod/
```

Expected: `public/` lists `public.zip` (about 3.5 GB) and `mod/` lists `mod.zip`.

## Step 2 — Build the macOS third-party libraries

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/libraries
JOBS=-j8 ./build-macos-libs.sh > ../../runs/T0.1-step2-macos-libs.log 2>&1; echo "EXIT=$?"
tail -n 30 ../../runs/T0.1-step2-macos-libs.log
```

Expected: `EXIT=0`. This can take 30–60 minutes.

## Step 3 — Build the bundled source libraries (SpiderMonkey, premake, …)

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/libraries
JOBS=-j8 ./build-source-libs.sh --without-nvtt > ../../runs/T0.1-step3-source-libs.log 2>&1; echo "EXIT=$?"
tail -n 30 ../../runs/T0.1-step3-source-libs.log
```

Expected: `EXIT=0`. SpiderMonkey takes a long time (20–60 minutes).

## Step 4 — Generate the makefiles

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/build/workspaces
./update-workspaces.sh --without-atlas --without-nvtt --without-tests -j8 > ../../../runs/T0.1-step4-workspaces.log 2>&1; echo "EXIT=$?"
tail -n 30 ../../../runs/T0.1-step4-workspaces.log
```

Expected: `EXIT=0` and a folder `gcc/` with a `Makefile` inside.

## Step 5 — Compile the game

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/build/workspaces/gcc
make config=release -j8 pyrogenesis > ../../../../runs/T0.1-step5-make.log 2>&1; echo "EXIT=$?"
tail -n 30 ../../../../runs/T0.1-step5-make.log
ls -la ../../../binaries/system/pyrogenesis
```

Expected: `EXIT=0` and the file `binaries/system/pyrogenesis` exists.

## Step 6 — Play one AI-vs-AI game without graphics (records the replay)

The game stops by itself after 30 minutes of real time at most.

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/binaries/system
touch ~/DEVELOPMENT/0ad-web/runs/T0.1-marker
/usr/bin/time -p perl -e 'alarm shift; exec @ARGV' 1800 \
  ./pyrogenesis -autostart="skirmishes/acropolis_bay_2p" \
  -autostart-ai=1:petra -autostart-ai=2:petra -autostart-player=-1 \
  -autostart-seed=0 -autostart-aiseed=0 -autostart-nonvisual -quickstart \
  > ~/DEVELOPMENT/0ad-web/runs/T0.1-step6-game.log 2>&1; echo "EXIT=$?"
tail -n 30 ~/DEVELOPMENT/0ad-web/runs/T0.1-step6-game.log
```

Expected: the game runs and ends (exit code 0, or 142 if the 30-minute alarm stopped it — both are fine).

## Step 7 — Find the recorded replay and copy it

```bash
find ~/Library/Application\ Support/0ad/replays -name commands.txt -newer ~/DEVELOPMENT/0ad-web/runs/T0.1-marker
```

Expected: exactly ONE path. Copy that folder:

```bash
cp -R "<the folder that contains that commands.txt>/." ~/DEVELOPMENT/0ad-web/fixtures/reference-replay/
ls -la ~/DEVELOPMENT/0ad-web/fixtures/reference-replay/
wc -l ~/DEVELOPMENT/0ad-web/fixtures/reference-replay/commands.txt
```

If it finds zero or more than one path: STOP and report the full `find` output.

## Step 8 — Replay it and measure the time (this is the native baseline)

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/binaries/system
/usr/bin/time -p ./pyrogenesis -replay="$HOME/DEVELOPMENT/0ad-web/fixtures/reference-replay/commands.txt" \
  > ~/DEVELOPMENT/0ad-web/runs/T0.1-step8-replay.log 2>&1; echo "EXIT=$?"
tail -n 40 ~/DEVELOPMENT/0ad-web/runs/T0.1-step8-replay.log
grep -ic "hash" ~/DEVELOPMENT/0ad-web/runs/T0.1-step8-replay.log
grep -i "mismatch\|error" ~/DEVELOPMENT/0ad-web/runs/T0.1-step8-replay.log | head -20
```

Expected: `EXIT=0`, the `real` time is printed, and there are no hash mismatch errors.
