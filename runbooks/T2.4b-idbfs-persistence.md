# Runbook T2.4b — Keep user data and config across visits (worker t01, port 8103)

Read `runbooks/_wave5-common.md` first. Report: `reports/T2.4b.md`.

Context (your T2.4a): in the browser the engine writes user data (savegames, replays) to
`/home/web_user/.local/share/0ad` and config to `/home/web_user/.config/0ad`. Today they live in
memory only and vanish on reload. Goal: persist exactly these two folders in IndexedDB (Emscripten
IDBFS). NOT cache, NOT logs.

Allowed edits: `tools/wasm/web-env.pre.js`, and in `tools/wasm/build-engine.sh` only the web
LDFLAGS (add `-lidbfs.js`, and `FS` to `EXPORTED_RUNTIME_METHODS` if needed for the test).

## Step 1 — Look first (no edits)
```bash
sed -n '1,80p' tools/wasm/web-env.pre.js
grep -nE 'web\)|EXPORTED_RUNTIME_METHODS|FORCE_FILESYSTEM|lidbfs|HOME' tools/wasm/build-engine.sh
grep -nE 'preRun|ENV' tools/wasm/web/index.html
```

## Step 2 — Implement in web-env.pre.js
1. In a `preRun` function (append to `Module.preRun`, keep existing entries working):
   for each of the two folders: `FS.mkdirTree(dir)`, `FS.mount(IDBFS, {}, dir)`.
   Then `addRunDependency('zeroad-idbfs')` and `FS.syncfs(true, cb)`; in `cb` log an error if any,
   then `removeRunDependency('zeroad-idbfs')`. The game must start even if IndexedDB fails.
2. Save back: a function `zeroadPersist()` that calls `FS.syncfs(false, cb)`, never runs two syncs at
   once (if one is running, mark "again" and run once more when it ends), logs errors.
   Call it every 10 s, on `visibilitychange` when hidden, and on `pagehide`.
   Expose `Module.zeroadPersist = zeroadPersist` for tests.
3. Make sure this code only runs on the main browser thread (not in pthread workers):
   guard with `typeof window !== 'undefined'` or the Emscripten `ENVIRONMENT_IS_PTHREAD` check.

## Step 3 — Build
Web build command from `_wave5-common.md` (task T2.4b). EXIT must be 0.

## Step 4 — Test A: a marker file survives reload
`runs/T2.4b/write.js`:
```js
(async () => { const F = Module.FS || FS; F.writeFile('/home/web_user/.config/0ad/marker.txt', 'hello-' + Date.now()); await new Promise((r) => { Module.zeroadPersist(); setTimeout(r, 3000); }); return F.readFile('/home/web_user/.config/0ad/marker.txt', { encoding: 'utf8' }); })()
```
`runs/T2.4b/read.js`:
```js
(() => { const F = Module.FS || FS; try { return F.readFile('/home/web_user/.config/0ad/marker.txt', { encoding: 'utf8' }); } catch (e) { return 'MISSING ' + e; } })()
```
```bash
perl -e 'alarm shift; exec @ARGV' 200 node tools/web/chrome-shot.mjs runs/web-t01 runs/T2.4b/a \
  "wait:25,evalfile:runs/T2.4b/write.js,reload,wait:25,evalfile:runs/T2.4b/read.js" "?arg=-mod=public&arg=-conf=windowed:true" 8103
```

Expected: read.js prints the same `hello-…` value as write.js.
