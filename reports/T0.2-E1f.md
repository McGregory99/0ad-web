## Findings for the supervisor

1. **The forced portable baseline interpreter works and is worth ~1.26×** (observed + derived):
   median eval time 5206 ms → 4144 ms for the same deterministic workload. The result values are
   unchanged, so this is a pure speed-up, not a behaviour change.
2. **The gain is modest, not dramatic** (derived): 20% less eval time on a mixed workload
   (property/method calls, `Map`, array iteration). **Inferred:** this is consistent with PBL
   replacing the C++ interpreter (Interpreter.cpp) with a computed-goto/baseline-style interpreter,
   but still being far from JIT speed — so a wasm build remains roughly an order of magnitude
   slower than native for hot loops.
3. **Variance is low after the rebuild** (derived): after-runs spread 33 ms vs 242 ms before,
   and the distributions are disjoint — the measurement is trustworthy despite the small n=3.
4. **Both link logs are clean** (observed): 0 `error` lines in `T0.2-E1f-link-before.log` and
   `T0.2-E1f-link-after.log`; no additional shims were needed beyond the E2c-2 set.
