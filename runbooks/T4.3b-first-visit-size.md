## Step 2 — What is inside pyrogenesis.data (preloaded files with sizes)
```bash
cd ~/DEVELOPMENT/0ad-web
grep -oE '"filename": *"[^"]*", *"start": *[0-9]+, *"end": *[0-9]+' runs/web-t41/pyrogenesis.js \
  | sed -E 's/"filename": *"([^"]*)", *"start": *([0-9]+), *"end": *([0-9]+)/\3 \2 \1/' \
  | awk '{printf "%10d %s\n", $1-$2, $3}' | sort -rn > runs/T4.3b/data-files.txt
wc -l < runs/T4.3b/data-files.txt; head -25 runs/T4.3b/data-files.txt
awk '{s+=$1} END {print "total bytes", s}' runs/T4.3b/data-files.txt
```
If the grep finds nothing, run `grep -o '"filename"[^}]*' runs/web-t41/pyrogenesis.js | head -3` and adapt only the sed pattern to that format.

## Step 3 — Compressed sizes (what a server with gzip/brotli would send)
```bash
cd ~/DEVELOPMENT/0ad-web/runs/web-t41
for f in pyrogenesis.js pyrogenesis.wasm pyrogenesis.data; do
  printf '%-18s raw=%10s gzip9=%10s' $f "$(stat -f %z $f)" "$(gzip -9 -c $f | wc -c | tr -d ' ')"
  if command -v brotli >/dev/null; then printf ' brotli=%10s' "$(brotli -c -q 11 $f | wc -c | tr -d ' ')"; fi
  if command -v zstd >/dev/null; then printf ' zstd19=%10s' "$(zstd -19 -c -q $f | wc -c | tr -d ' ')"; fi
  echo
done | tee ../T4.3b/compressed.txt
```

## Step 5 — ICU data: what the engine uses and whether we can filter it
```bash
cd ~/DEVELOPMENT/0ad-web
grep -rhoE 'icu::[A-Za-z]+|unicode/[a-z0-9_]+\.h|u_[a-zA-Z]+|ucol_[a-zA-Z]+|ubrk_[a-zA-Z]+' upstream/source --include='*.cpp' --include='*.h' | sort | uniq -c | sort -rn | head -40 > runs/T4.3b/icu-use.txt
cat runs/T4.3b/icu-use.txt
unzip -l upstream/binaries/data/mods/public/public.zip | awk '{print $4}' | grep -oE 'l10n/[a-zA-Z_]+\.' | sort -u | head -80 > runs/T4.3b/game-locales.txt
wc -l < runs/T4.3b/game-locales.txt; tr '\n' ' ' < runs/T4.3b/game-locales.txt; echo
ls tools/emsdk/upstream/emscripten/cache/ports/icu/icu/source/data/in/
for p in "$(command -v icupkg)" /opt/homebrew/opt/icu4c*/bin/icupkg /usr/local/opt/icu4c*/bin/icupkg; do [ -x "$p" ] && echo "icupkg: $p"; done
```
If an `icupkg` was found (call it $ICUPKG), also run (scratch only):

