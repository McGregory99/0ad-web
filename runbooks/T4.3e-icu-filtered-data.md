# Runbook T4.3e — Build a smaller icudt68l.dat (worker t13)

Read `runbooks/_wave5-common.md` first. Report: `reports/T4.3e.md`. Write files ONLY under
`runs/T4.3e/`. Do not edit build scripts (another worker is editing `build-engine.sh`).

Context: your T4.3d shows the engine uses locales, display names, dates, calendars, time zones,
numbers and UTF-8 strings, and never collation, break iteration, transliteration, normalization
data, converters, character names, rbnf or units. Goal: remove those items from the existing
28.6 MB data file with `icupkg` (no full ICU data rebuild).

Tool: `upstream/libraries/macos/icu/sbin/icupkg` (native macOS). Input:
`tools/emsdk/upstream/emscripten/cache/ports/icu/icu/source/data/in/icudt68l.dat`.

## Step 1 — Tool version and item list
```bash
I=upstream/libraries/macos/icu; ls $I/bin $I/sbin; $I/bin/icuinfo 2>&1 | head -5
mkdir -p runs/T4.3e
DYLD_LIBRARY_PATH=$I/lib $I/sbin/icupkg -l tools/emsdk/upstream/emscripten/cache/ports/icu/icu/source/data/in/icudt68l.dat > runs/T4.3e/items.txt; echo "EXIT=$?"; wc -l runs/T4.3e/items.txt
sed -E 's#/.*##' runs/T4.3e/items.txt | sort | uniq -c | sort -rn | head -30
```
If `icupkg` fails to run (missing libraries), try with `DYLD_LIBRARY_PATH` set as above; if it still
fails, STOP with STATUS: blocked and paste the error.

## Step 2 — Remove list
Write `runs/T4.3e/remove.txt` (one item per line, exact names from items.txt) with:
- every item under `coll/`, `brkitr/`, `translit/`, `rbnf/`, `unit/`
- every `*.cnv` item, `cnvalias.icu`, `unames.icu`, `uts46.nrm`, `nfkc_cf.nrm`, `nfkc.nrm`
  (keep `nfc.nrm` — the locale and formatting code may need it)
- locale data files (top-level `xx.res`, `xx_YY.res`, and the same under `curr/`, `lang/`,
  `region/`, `zone/`) for locales NOT in this keep list: `root`, `en`, `en_*`, and the 27 shipped
  locales from your T4.3d Step 2 (each with its `_*` children and script variants). Keep
  `res_index.res`, `pool.res` and every non-locale item not named above.
Do this with a small script in `runs/T4.3e/` and print counts per folder of removed vs kept.

## Step 3 — Build the smaller file
```bash
I=upstream/libraries/macos/icu
cp tools/emsdk/upstream/emscripten/cache/ports/icu/icu/source/data/in/icudt68l.dat runs/T4.3e/full.dat
DYLD_LIBRARY_PATH=$I/lib $I/sbin/icupkg -r runs/T4.3e/remove.txt runs/T4.3e/full.dat runs/T4.3e/icudt68l.dat; echo "EXIT=$?"
ls -l runs/T4.3e/full.dat runs/T4.3e/icudt68l.dat
brotli -q 11 -c runs/T4.3e/icudt68l.dat | wc -c
DYLD_LIBRARY_PATH=$I/lib $I/sbin/icupkg -l runs/T4.3e/icudt68l.dat | wc -l
```

## Step 4 — Does it load? (only if the macOS ICU is version 68)
If Step 1 shows ICU 68.x: `mkdir -p runs/T4.3e/datadir && cp runs/T4.3e/icudt68l.dat runs/T4.3e/datadir/`
then `ICU_DATA=$PWD/runs/T4.3e/datadir DYLD_LIBRARY_PATH=$I/lib $I/bin/icuinfo -v 2>&1 | head -20`
and the same with `$I/bin/uconv --version` if present. Report the output. If not version 68, write
"skipped: macOS ICU is <version>".
