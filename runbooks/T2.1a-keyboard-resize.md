## Step 2 — Probe file
Create `runs/T2.1a/size.js` with exactly:
```js
(() => { const c = document.getElementById('canvas');
  return { inner: [innerWidth, innerHeight], canvas: [c.width, c.height], css: [c.clientWidth, c.clientHeight], dpr: devicePixelRatio,
    active: document.activeElement && document.activeElement.tagName }; })()
```

## Step 3 — In-game keys (one run; real GPU)
```bash
cd ~/DEVELOPMENT/0ad-web
START='click:491:553,wait:2,click:180:221,wait:3,click:418:221,wait:8,click:1185:681'
CHROME_GPU=1 perl -e 'alarm shift; exec @ARGV' 300 node tools/web/chrome-shot.mjs runs/web-tsk runs/T2.1a/keys \
  "wait:20,$START,wait:25,evalfile:runs/T2.1a/size.js,shot:k0-start,keydown:ArrowLeft,wait:2,keyup:ArrowLeft,wait:1,shot:k1-left,keydown:w,wait:2,keyup:w,wait:1,shot:k2-w,key:Escape,wait:2,shot:k3-escape,key:Escape,wait:2,shot:k4-escape2,key:Enter,wait:2,key:h,key:i,wait:1,shot:k5-chat,key:Escape,wait:2,shot:k6-closed" \
  '?arg=-mod=public&arg=-conf=windowed:true' 8150
grep -vE 'GPU stall' runs/T2.1a/keys/console.log | grep -E 'key|evalfile|exception|ERROR|shot' | head -40
md5 -q runs/T2.1a/keys/*.png | paste - - - - - - - ; ls runs/T2.1a/keys/*.png
```
Equal md5 for two consecutive shots means the key changed nothing on screen.

## Step 4 — Window sizes (menu only)
For each size `1920x1080`, `1024x768`, `800x600`:
```bash
cd ~/DEVELOPMENT/0ad-web
CHROME_W=1920 CHROME_H=1080 perl -e 'alarm shift; exec @ARGV' 150 node tools/web/chrome-shot.mjs runs/web-tsk runs/T2.1a/size-1920x1080 \
  'wait:25,evalfile:runs/T2.1a/size.js,shot:menu' '?arg=-mod=public&arg=-conf=windowed:true' 8150
grep -E 'evalfile|exception|ERROR' runs/T2.1a/size-1920x1080/console.log
```
(change `CHROME_W`, `CHROME_H` and the folder name for the other two sizes).
