# Runbook T7.1c/d — Native 0 A.D. and the browser play together (worker t71c)

Read `runbooks/_wave7-common.md` first. Report: `reports/T7.1c.md`. Logs: `runs/T7.1c/`.

## Background (supervisor)

`tools/web/mp-check.mjs` already runs a two-browser match through the relay
(`tools/relay/relay.mjs`): the host page autostarts `scenarios/arcadia` with
`-autostart-host -autostart-host-players=2`, its ENet socket asks the relay for UDP port 20595,
and the client page joins `127.0.0.1` (port 20595 by default). Because the relay owns a real UDP
socket on this Mac for the browser host, a **native** client can join `127.0.0.1:20595` too
(T7.1c), and a browser client can join a **native** host listening on UDP 20595 (T7.1d).

Native game (built in T0.1): `upstream/binaries/system/pyrogenesis`, data in
`upstream/binaries/data/mods/{mod,public}`. It prints `GAME STARTED, ALL INIT COMPLETE` on stdout
when a match starts (`upstream/source/ps/Game.cpp:369`). Its logs go to
`~/Library/Application Support/0ad/logs/mainlog.html` (read-only for you; copy, never delete).
Useful native options: `-mod=public`, `-autostart=scenarios/arcadia`, `-autostart-host`,
`-autostart-host-players=2`, `-autostart-client=127.0.0.1`, `-autostart-playername=<name>`,
`-autostart-nonvisual` (no window, no sound).


Expected: no crash before the alarm; it waits for a second player. Report the tail.
If it exits with an error about nonvisual mode, retry once without `-autostart-nonvisual` and with
`-conf=windowed:true -xres=800 -yres=600` (a window will appear; that is fine) and use that
variant ("NATIVE_VISUAL") everywhere below.

## Step 3 — Add a native side to mp-check.mjs
Add env `MP_NATIVE` with values `client` or `host` (unset = today's behaviour, unchanged).
Write it like this:

1. Header comment: document `MP_NATIVE=client` (browser host, native client joins
   127.0.0.1) and `MP_NATIVE=host` (native host, browser client joins 127.0.0.1), and
   `MP_NATIVE_ARGS` (extra native arguments, space-separated, e.g. `-autostart-nonvisual`).
2. A function `startNative(role)` that spawns
   `<root>/upstream/binaries/system/pyrogenesis` with `cwd` = that directory and arguments
   `-mod=public`, then for `host`: `-autostart=${MAP} -autostart-host -autostart-host-players=2
   -autostart-playername=native`, for `client`: `-autostart-client=127.0.0.1
   -autostart-playername=native`, then `MP_NATIVE_ARGS` split on spaces (ignore empty).
   Its stdout+stderr go line by line to `<outdir>/native.log` (with `[stamp]` prefixes like the
   pages) and into an in-memory `lines` array. It returns an object shaped like a page:
   `{ name: 'native', lines, started: null, matchLineIndex, proc }`; set `started` and
   `matchLineIndex` when a line contains `GAME STARTED`, and `say('native: in the match')`.
   Kill it in `cleanup()` (`proc.kill('SIGKILL')` if it is still running).
3. Flow:
   - `MP_NATIVE=client`: open only the host page (as now), wait for `host.bound`, then
     `startNative('client')` instead of opening the client page.
   - `MP_NATIVE=host`: `startNative('host')` first, `await sleep(15000)` (the native host needs a
     few seconds to listen), then open only the client page with `clientQuery`.
   - Both: wait until the browser page and the native side have `started`, then stay
     `matchSeconds` in the match, logging the browser page's stats every 30 s and also the count
     of native lines containing `Turn` or `turn` (if any) — report what native prints during a
     match.
4. Summary for the native side: `reachedMatch`, `matchStartSeconds`, `exited` (exit code or null
   if still running at the end), `desyncLines` (same regex as the pages), `errorLines`
   (lines matching `/ERROR|error:/`, first 40). Copy
   `~/Library/Application Support/0ad/logs/mainlog.html` to `<outdir>/native.mainlog.html` at the
   end (use `copyFileSync`; ignore a missing file). Add `native` to `summary.json`.
5. PASS rule with a native side: the browser page reached the match, the native side reached the
   match and is still running at the end, no desync line on either side, the browser page's
   `sent` and `received` stats grew during the match, and the browser page is still connected
   (the existing `connected()` check). The two-browser PASS rule stays as it is.
Keep the existing two-browser code path working: do not rename or remove anything it uses.

Syntax check: `node --check tools/web/mp-check.mjs; echo EXIT=$?` → EXIT=0.
