# Runbook T0.3 — THE GATE: reference replay in WebAssembly (Node, headless)

Goal: run the reference replay with `pyrogenesis.wasm` in Node and compare it with native.
Native reference: final state `6908836f8d8ca50562faab971ad0c4ca`, about 35–38 s.
Gate: same hash, and time ≤ ~3× native (≈105–117 s). Whatever the result, you only REPORT.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT). You may write only in `ROOT/runs/` and in the temporary
  HOME directory created below (outside the repository).
- Report: `ROOT/reports/T0.3.md`
- The build uses the `node` profile: the wasm reads the Mac's files directly (NODERAWFS).
  `ZEROAD_EXECUTABLE` tells the engine where it "lives", so it finds `binaries/data`.
- Every run is wrapped in `perl -e 'alarm shift; exec @ARGV' <seconds>` so it stops by itself.

## Step 1 — Smoke test

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/binaries/system-wasm
ls -la pyrogenesis pyrogenesis.wasm
H=$(mktemp -d); echo "TEMP HOME=$H"
HOME=$H ZEROAD_EXECUTABLE=$PWD/pyrogenesis perl -e 'alarm shift; exec @ARGV' 120 node pyrogenesis -version; echo "EXIT=$?"
```

Expected: a line `Pyrogenesis ...` and `EXIT=0`. If not, paste everything and go to the report.

## Step 2 — The replay (can take several minutes; limit 30 minutes)

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/binaries/system-wasm
REPLAY="$HOME/DEVELOPMENT/0ad-web/fixtures/reference-replay/commands.txt"
HOME=$H ZEROAD_EXECUTABLE=$PWD/pyrogenesis /usr/bin/time -p perl -e 'alarm shift; exec @ARGV' 1800 \
  node pyrogenesis -replay="$REPLAY" > ~/DEVELOPMENT/0ad-web/runs/T0.3-wasm-replay.log 2>&1; echo "EXIT=$?"
L=~/DEVELOPMENT/0ad-web/runs/T0.3-wasm-replay.log
grep 'Final state' $L; grep -E '^(real|user|sys) ' $L; grep -ciE 'mismatch|error' $L
tail -n 30 $L
```

Note: in Step 2 `$HOME` in `REPLAY=` is your real home; `HOME=$H` only applies to the node command.
`$H` must still be set from Step 1 (same shell). If it is not, run `H=$(mktemp -d)` again.

## Step 3 — If Step 2 crashed or timed out: collect evidence only

```bash
L=~/DEVELOPMENT/0ad-web/runs/T0.3-wasm-replay.log
grep -nE 'Aborted|RuntimeError|exception|ERROR|Assertion|out of memory|stack' $L | head -30
grep -nE 'Turn [0-9]+' $L | tail -3
```
