# Runbook T8.1a — License and trademark inventory for a public web build (READ-ONLY, worker t13)

Read `runbooks/_wave4-common.md` first. Report: `reports/T8.1a.md`. Logs: `runs/T8.1a-*.txt`.
You only READ and REPORT. No network access needed. No edits except your report and logs.

Goal: list every license that applies to what the browser build ships (engine code, game data,
libraries compiled into pyrogenesis.wasm) and what each one requires us to show or provide.

## Step 1 — Upstream license files
```bash
cd ~/DEVELOPMENT/0ad-web/upstream
ls; ls LICENSE* license* COPYING* 2>/dev/null
find . -maxdepth 4 \( -iname 'LICENSE*' -o -iname 'COPYING*' -o -iname 'license_*.txt' \) -not -path './libraries/source/*' | sort > ../runs/T8.1a-files.txt
wc -l < ../runs/T8.1a-files.txt; cat ../runs/T8.1a-files.txt | head -60
sed -n '1,80p' LICENSE.md 2>/dev/null || sed -n '1,80p' LICENSE.txt
```
Read the top-level license file(s) completely and quote the parts that say which license covers code, art, sound and fonts.

## Step 2 — Trademark and name use
```bash
cd ~/DEVELOPMENT/0ad-web/upstream
grep -rniI 'trademark\|wildfire games' --include='*.md' --include='*.txt' . 2>/dev/null | grep -v '/libraries/source/' | head -30
```

## Step 3 — Libraries linked into the web build
```bash
cd ~/DEVELOPMENT/0ad-web
ls wasm/pkgconfig/
grep -h '^Libs:' wasm/pkgconfig/*.pc | head -40
grep -oE '\-s *USE_[A-Z0-9_]+=[0-9]+|-l[a-zA-Z0-9_]+' runs/engine-make.log | sort | uniq -c | sort -rn | head -40
ls tools/emsdk/upstream/emscripten/cache/ports/ 2>/dev/null
ls wasm/deps/prefix/lib 2>/dev/null
```
For each library found, find its license file (look in `tools/emsdk/upstream/emscripten/cache/ports/<name>/`,
`wasm/deps/`, `wasm/spidermonkey/`, `upstream/libraries/source/`). Use `find <dir> -maxdepth 3 -iname 'LICENSE*' -o -maxdepth 3 -iname 'COPYING*'` and read the first 15 lines to name the license.

## Step 4 — Game data licenses
```bash
cd ~/DEVELOPMENT/0ad-web/upstream/binaries/data
find . -maxdepth 3 -iname '*licen*' -o -maxdepth 3 -iname '*copying*' -o -maxdepth 3 -iname '*credits*' | head
unzip -l mods/public/public.zip | grep -iE 'licen|copying|credits|readme' | head -20
unzip -l mods/mod/mod.zip | grep -iE 'licen|copying|credits|readme' | head -20
```
