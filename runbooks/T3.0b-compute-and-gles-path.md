# Runbook T3.0b — Compute shaders and the existing GLES path (READ-ONLY)

Goal: find which features use compute shaders (WebGL2 has none) and how the existing
OpenGL ES code path works. You only READ and REPORT. No changes in `upstream/`.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT) — Report: `ROOT/reports/T3.0b.md`
- Shaders were extracted earlier into `ROOT/wasm/inventory/shaders/`.

## Step 1 — Compute shader files and who references them

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/inventory/shaders
find . -name '*.cs' | sort
for f in $(find . -name '*.cs' -exec basename {} .cs \;); do echo "== $f"; grep -rl "$f" --include='*.xml' . | head -10; done
```

## Step 2 — Compute usage in the engine

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
grep -rnE 'Dispatch\(|ComputeShader|COMPUTE|compute' --include='*.cpp' --include='*.h' renderer graphics ps | grep -v '/tests/' | head -60
```

## Step 3 — Config options that switch features on/off

```bash
cd ~/DEVELOPMENT/0ad-web/upstream
grep -nE '^\[|^(renderer\.|preferglsl|gpuskinning|shadows|shadowpcf|water|postproc|fog|antialiasing|sharpening|upscale|silhouettes|particles|textures\.|vsync|rendererbackend|renderpath)' binaries/data/config/default.cfg | head -80
```

## Step 4 — The GLES path

```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
grep -n 'CONFIG2_GLES' -A3 lib/config2.h
grep -n 'gles' ../build/premake/premake5.lua ../build/premake/extern_libs5.lua | head -30
grep -n 'CONFIG2_GLES' renderer/backend/gl/ShaderProgram.cpp renderer/backend/gl/Device.cpp | head -40
sed -n '1,80p' lib/external_libraries/opengles2_wrapper.h
```

## Step 5 — Shader preprocessor macros used by GLSL files

```bash
cd ~/DEVELOPMENT/0ad-web/wasm/inventory/shaders
grep -rhoE '\b(SAMPLE_[A-Z0-9_]+|USE_[A-Z0-9_]+|GLSL_[A-Z0-9_]+|IS_[A-Z0-9_]+)\b' --include='*.fs' --include='*.vs' --include='*.h' . | sort | uniq -c | sort -rn | head -60
find . -path '*glsl*' -name '*.h' | sort
```
