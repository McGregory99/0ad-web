# Runbook T3.2a — What blocks GLSL ES 3.00 shaders and real shadows (READ-ONLY, worker t10)

Read `runbooks/_wave4-common.md` first. Report: `reports/T3.2a.md`. Logs: `runs/T3.2a-*.txt`.
You only READ and REPORT. No edits anywhere except your report and `runs/T3.2a-*.txt`.

Background: the browser build uses the engine's GLES2 path (GLSL ES 1.00). WebGL2 cannot do the
shadow sampler there, so shadows are blocky. The fix is GLSL ES 3.00 (`#version 300 es`). We need a map
of the work. Shaders were extracted earlier to `wasm/inventory/shaders/`; the overlay copy of one fixed
shader is in `tools/wasm/web/overlay/public/shaders/glsl/`.

## Step 1 — How the engine builds a GLSL program (version line, defines, GLES branches)
```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
grep -n '#version\|GLSL_VERSION\|CONFIG2_GLES\|USE_SHADOW\|shadow\|"#define\|precision' renderer/backend/gl/ShaderProgram.cpp | head -80 > ../../runs/T3.2a-program.txt
grep -rn 'version' graphics/ShaderManager.cpp renderer/backend/gl/ShaderProgram.cpp | head -40 >> ../../runs/T3.2a-program.txt
cat ../../runs/T3.2a-program.txt
```

## Step 2 — Shadow map creation and sampling options
```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
grep -rn 'COMPARE\|ShadowSampler\|shadowSampler\|SHADOW_SAMPLER\|USE_SHADOW_PCF\|DEPTH_COMPONENT\|ShadowPCF\|shadowpcf' \
  renderer graphics ps --include='*.cpp' --include='*.h' | grep -v /tests/ | head -60 > ../../runs/T3.2a-shadow.txt
cat ../../runs/T3.2a-shadow.txt
grep -n 'shadow' ../binaries/data/config/default.cfg
```

## Step 3 — Shader files: GLSL 1.00-only constructs per file
```bash
cd ~/DEVELOPMENT/0ad-web/wasm/inventory/shaders
for f in $(find . -path '*glsl*' \( -name '*.vs' -o -name '*.fs' -o -name '*.h' \) | sort); do
  printf '%-55s attr=%-3s vary=%-3s tex2D=%-3s texCube=%-3s fragColor=%-3s fragData=%-3s shadow2D=%-3s ext=%-3s\n' "$f" \
    "$(grep -c '\battribute\b' $f)" "$(grep -c '\bvarying\b' $f)" "$(grep -c 'texture2D' $f)" "$(grep -c 'textureCube' $f)" \
    "$(grep -c 'gl_FragColor' $f)" "$(grep -c 'gl_FragData' $f)" "$(grep -c 'shadow2D' $f)" "$(grep -c '#extension' $f)"
done > ../../../runs/T3.2a-constructs.txt; wc -l < ../../../runs/T3.2a-constructs.txt; cat ../../../runs/T3.2a-constructs.txt
```

## Step 4 — Shadow and loop code in shaders
```bash
cd ~/DEVELOPMENT/0ad-web/wasm/inventory/shaders
grep -rn 'USE_SHADOW\|sampler2DShadow\|shadow2D\|SHADOWS\|get_shadow\|PCF' . | head -60 > ../../../runs/T3.2a-shadercode.txt
echo '== for loops' >> ../../../runs/T3.2a-shadercode.txt
grep -rn 'for *(' --include='*.fs' --include='*.vs' --include='*.h' . >> ../../../runs/T3.2a-shadercode.txt
cat ../../../runs/T3.2a-shadercode.txt
```

## Step 5 — Which shader programs the default settings use (XML programs that are GLSL)
```bash
cd ~/DEVELOPMENT/0ad-web/wasm/inventory/shaders
find . -path '*glsl*' -name '*.xml' | sort | head -80
grep -ln 'shadow' $(find . -path '*glsl*' -name '*.xml') 2>/dev/null
```
