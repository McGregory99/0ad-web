### Recommended block size (**inferred**): 64 KiB

Why: bytes are the dominant cost, and 64 KiB cuts the match download from 483.4 MB (256 KiB) to
365.0 MB (−118.4 MB, −24.5%), essentially as low as 32 KiB (363.3 MB, only 1.7 MB less). 64 KiB keeps
the request count at 1,542 instead of 1,901 (32 KiB) and spends 3,238 ms in fetches instead of
4,060 ms, so it avoids the request/latency explosion of 32 KiB. 128 KiB is a middle option if
request count matters more than bytes (1,256 requests, 404.6 MB, 2,339 ms). Menu bytes also drop
from 28.34 MB (256 KiB) to 20.28 MB (64 KiB), i.e. the first paint gets ~8 MB lighter.
