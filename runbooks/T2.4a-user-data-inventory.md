## Step 1 — Path setup in the engine
```bash
cd ~/DEVELOPMENT/0ad-web/upstream/source
```

## Step 3 — What the browser build sees at run time
```bash
cd ~/DEVELOPMENT/0ad-web
grep -iE 'path|user|config|cache|log|home|write|cfg' upstream/binaries/system-web/../../../runs/T4.2-shot-7/console.log 2>/dev/null | head -20
ls runs/ | grep -E 'shot|web-' | head
for d in runs/T2.3a/game runs/T2.3a/after; do [ -f $d/console.log ] && grep -iE 'path|user|config|cache|logs|home|writ|cfg|savegame' $d/console.log | head -20; done
grep -n 'HOME\|ENV\.' tools/wasm/web-env.pre.js tools/wasm/web-lib.js tools/wasm/web/index.html
```

## Step 4 — Emscripten file systems available in this SDK
