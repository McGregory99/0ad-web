# Runbook T8.1b — Licenses page for the web build (worker t13)

Read `runbooks/_wave4-common.md` first. Input: YOUR report `reports/T8.1a.md`. Report: `reports/T8.1b.md`.
You may create files ONLY under `tools/wasm/web/licenses/`. Do not edit anything else (the supervisor wires it into the build).

Goal: a static page `licenses.html` plus the license texts, so the hosted game can link "Licenses and source".

## Step 1 — Copy the license texts (unchanged bytes)
```bash
mkdir -p ~/DEVELOPMENT/0ad-web/tools/wasm/web/licenses/texts
```
For every component in your T8.1a table, copy its license file (the exact file you cited there) to
`tools/wasm/web/licenses/texts/<component>.txt` with `cp`. Font and art license files that live inside
`mod.zip`/`public.zip`: extract them with `unzip -p <zip> <path> > tools/wasm/web/licenses/texts/<name>.txt`.
Do not rewrite or shorten license texts.

## Step 2 — Write `tools/wasm/web/licenses/licenses.html`
Plain HTML, no scripts, no external CSS/fonts/images, English. Content, in this order:
1. Title "0 A.D. in the browser — licenses and source".
2. One paragraph: this is an unofficial browser port of 0 A.D. by Wildfire Games (link http://www.wildfiregames.com/);
   it is not made or endorsed by Wildfire Games.
3. "Engine code": GPL-2.0-or-later, link to `texts/<gpl file>`; a line "Source code of this build: SOURCE_URL"
   (keep the literal placeholder SOURCE_URL; the supervisor fills it).
4. "Game art and audio": CC-BY-SA 3.0, Wildfire Games attribution, link https://creativecommons.org/licenses/by-sa/3.0/.
5. "Fonts": one line each with license name and link to its text.
6. "Libraries compiled into the game": a table Component | License | Text (link), one row per component from T8.1a.
7. "SpiderMonkey": MPL 2.0 line with link, and a line that its source is part of SOURCE_URL.
Every `texts/...` link must point to a file you created in Step 1.

## Step 3 — Check links
```bash
cd ~/DEVELOPMENT/0ad-web/tools/wasm/web/licenses
grep -o 'href="texts/[^"]*"' licenses.html | sed 's/href="//;s/"$//' | while read f; do [ -f "$f" ] && echo "ok $f" || echo "MISSING $f"; done
ls -la texts | head -50; du -sh .
```
Expected: no MISSING lines.
