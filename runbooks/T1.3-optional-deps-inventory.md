# Runbook T1.3a — Inventory of optional dependencies (READ-ONLY)

Goal: find every place in the engine that uses a dependency we will remove or stub
for the browser build. You only READ and REPORT. You change nothing in `upstream/`.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT)
- Report: `ROOT/reports/T1.3a.md`

Dependencies to inventory. Each line is: number. name — PATTERN — premake option — macro.
Copy the PATTERN exactly, including the single quotes (the `|` characters are regex alternation).

1. Atlas editor — PATTERN `'Atlas|AtlasUI|ATLAS'` — `--without-atlas` — none
2. FCollada / Collada — PATTERN `'Collada|collada|FCollada'` — none — none
3. NVTT — PATTERN `'nvtt|NVTT'` — `--without-nvtt` — MACRO `CONFIG2_NVTT`
4. miniupnpc — PATTERN `'miniupnpc|upnp|UPnP'` — `--without-miniupnpc` — MACRO `CONFIG2_MINIUPNPC`
5. gloox / lobby — PATTERN `'gloox|CONFIG2_LOBBY|XmppClient'` — `--without-lobby` — MACRO `CONFIG2_LOBBY`
6. libcurl / mod.io — PATTERN `'curl|ModIo|mod\.io'` — none — none
7. Crash handler / debugger — PATTERN `'crashlog|dbghelp|debug_DumpStack|sys_display_error'` — none — none
8. ENet networking — PATTERN `'enet_|#include <enet'` — none — none
9. Vulkan backend — PATTERN `'renderer/backend/vulkan|VK_|vk[A-Z]'` — none — none
10. OpenGL backend — PATTERN `'renderer/backend/gl|CONFIG2_GLES|glDraw'` — `--gles` — MACRO `CONFIG2_GLES`

## Steps

For EACH of the 10 items, run these three commands, replacing `'PATTERN'` with the item's pattern (single quotes included):

```bash
cd ~/DEVELOPMENT/0ad-web/upstream
grep -rIlE 'PATTERN' source --include='*.cpp' --include='*.h' | grep -v '/tests/' | sort | wc -l
grep -rIlE 'PATTERN' source --include='*.cpp' --include='*.h' | grep -v '/tests/' | sort | head -40
grep -rIcE 'PATTERN' source --include='*.cpp' --include='*.h' | grep -v ':0$' | grep -v '/tests/' | sort -t: -k2 -nr | head -10
```

Then, for the items with a MACRO (3, 4, 5, 10), also run:

```bash
grep -rIn "MACRO" source --include='*.cpp' --include='*.h' | wc -l
```

Then run once:

```bash
cd ~/DEVELOPMENT/0ad-web/upstream
grep -nE 'without-|_OPTIONS|newoption' build/premake/premake5.lua | head -40
grep -nE '"libcurl"|"enet"|"gloox"|"miniupnpc"|"nvtt"|"fcollada"|"sdl"|"openal"|"spidermonkey"|"icu"|"sodium"|"freetype"|"libxml2"|"libpng"|"zlib"|"vorbis"|"fmt"|"boost"' build/premake/premake5.lua | head -60
```
