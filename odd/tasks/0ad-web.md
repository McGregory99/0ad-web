# 0ad-web — 0 A.D. 0.28.0 playable in the browser (WebAssembly)

Objective: port (not rewrite) the pyrogenesis engine 0.28.0 to WebAssembly with Emscripten. Branch: `main`.
Delivery: `ask-on-risk`. Execution: Opus supervises and writes runbooks; pi workers (local `qwen3.6-35b-a3b`) execute them in Herdr panes. Test runner: native/wasm replay hash comparison.

- **S7** — First playable milestone: single player vs AI, desktop Chrome, light data profile (menu + 1 map + 2 civs, under 300 MB).
- **S8** — Quality bar, user verbatim (L20): "el objetivo es sacarlo lo antes posible pero claramente cumplir unos criterios de calidad en la experiencia de juego". Supervisor-proposed criteria (assumptions until the user amends them), measured on this Mac (M-series, 8 cores) in desktop Chrome:
  - Q1 Determinism: browser and Node replays reproduce the native reference hash.
  - Q2 Simulation cost per 200 ms turn (reference replay, 2 Petra AIs): p50 <= 20 ms, p99 <= 50 ms, max <= 100 ms (no turn longer than half a turn).
  - Q3 Frame rate during the reference skirmish: median >= 30 fps, 1% low >= 20 fps at 1920x1080, default web graphics settings.
  - Q4 Loading: main menu <= 20 s on first visit (100 Mbit/s) and <= 5 s cached; match start <= 30 s.
  - Q5 Input: click/key to visible feedback <= 100 ms.
  - Q6 Stability: a 60-minute skirmish with no crash and wasm memory <= 3 GB.

Evidence from the shipped DMG (REA, 2026-11-06): `pyrogenesis` 86 MB arm64, statically links ICU, gloox, SDL2, SpiderMonkey, OpenAL, miniupnpc, libsodium, FreeType; separate MoltenVK/AtlasUI/Collada dylibs; `public.zip` 3.5 GB (52,829 files: DDS 2.1 GB, PMD 345 MB, OGG 269 MB, cached XMB).
