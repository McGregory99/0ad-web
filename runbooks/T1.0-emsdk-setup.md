# Runbook T1.0 — Install the Emscripten SDK locally and smoke-test threads

Goal: have a working Emscripten toolchain inside the project (not system-wide),
and prove that C code with pthreads compiles to WebAssembly and runs in Node.

- Root: `~/DEVELOPMENT/0ad-web` (ROOT)
- You may create ONLY: `ROOT/tools/emsdk/` (the SDK) and `ROOT/tools/smoke/`
- Logs: `ROOT/runs/`
- Report: `ROOT/reports/T1.0.md`

## Step 1 — Download the SDK

```bash
cd ~/DEVELOPMENT/0ad-web && mkdir -p tools runs reports
git clone --depth 1 https://github.com/emscripten-core/emsdk.git tools/emsdk 2>&1 | tail -3
```

Expected: folder `tools/emsdk` exists.

## Step 2 — Install and activate the latest release

```bash
cd ~/DEVELOPMENT/0ad-web/tools/emsdk
./emsdk install latest > ../../runs/T1.0-install.log 2>&1; echo "EXIT=$?"
tail -n 15 ../../runs/T1.0-install.log
./emsdk activate latest > ../../runs/T1.0-activate.log 2>&1; echo "EXIT=$?"
tail -n 15 ../../runs/T1.0-activate.log
```

Expected: both `EXIT=0`. Do NOT run any command that edits `~/.zshrc` or other profile files.

## Step 3 — Check versions

```bash
cd ~/DEVELOPMENT/0ad-web/tools/emsdk && source ./emsdk_env.sh > /dev/null 2>&1
emcc --version | head -1
node --version
```

Expected: an `emcc` version line and a Node version.

## Step 4 — Smoke test with threads

Create `~/DEVELOPMENT/0ad-web/tools/smoke/hello_threads.c` with EXACTLY this content:

```c
#include <pthread.h>
#include <stdio.h>

static int result = 0;

static void *worker(void *arg) {
    result = *(int *)arg * 2;
    return NULL;
}

int main(void) {
    pthread_t t;
    int value = 21;
    if (pthread_create(&t, NULL, worker, &value) != 0) {
        printf("thread create failed\n");
        return 1;
    }
    pthread_join(t, NULL);
    printf("thread ok %d\n", result);
    return result == 42 ? 0 : 2;
}
```

Then:

```bash
cd ~/DEVELOPMENT/0ad-web/tools/emsdk && source ./emsdk_env.sh > /dev/null 2>&1
cd ~/DEVELOPMENT/0ad-web/tools/smoke
emcc -O2 -pthread -sPTHREAD_POOL_SIZE=2 -sEXIT_RUNTIME=1 hello_threads.c -o hello_threads.js 2>&1 | tail -10; echo "BUILD_EXIT=$?"
ls -la hello_threads.*
node hello_threads.js; echo "RUN_EXIT=$?"
```

Expected: `thread ok 42` and `RUN_EXIT=0`.
